1 · Counting jumps and kinks

ContinuityNewSat · WTA20

Questions that ask for the number of points where a function is discontinuous or not derivable are bookkeeping questions. You need a complete list of candidate points, and one test for each. You got all three wrong on WTA20, and this pattern had not shown up before, so it is new. The tests below catch the usual errors: two jumps that cancel, a kink that a zero factor smooths out, and a vertical tangent.

Your answer was 15. Correct answer: 30. Here's why.

Step 2 · the breaks of [5x] [5x] jumps up by 1 at every x = k/5. In (0, 5] that is k = 1, …, 25: 25 points.
Step 3 · the breaks of −[3x] −[3x] jumps down by 1 at every x = k/3, k = 1, …, 15: 15 points.

At x = 5 the left limit is 24 − 14 + 15 = 25 and f(5) = 25 − 15 + 15 = 25, so it is continuous (one of the cancelled five).

The shortcuts
  • List first. For [kx] and {kx} the breaks are at the multiples of 1/k. For |p(x)| the kinks are at the roots of p. For a circle piece, the joins and the top.
  • Rewrite {kx} = kx − [kx]. Then everything is floors plus a line, and the line never matters for continuity.
  • Same point, opposite jumps: they cancel. Count = (first list) + (second list) − 2 × (points in both).
  • A kink times a factor that is 0 there is smooth. |x−1|(x²−1) is derivable at x = 1 because x²−1 = 0 there.
  • A vertical tangent next to a finite slope is a non-derivable point. Square-root and semicircle pieces do this.
  • Check the ends of the interval alone, using one-sided limits only.

2 · Max, min and running minimum

ContinuityNewSat · WTA20

A max or min of two functions, or a running minimum, is a function built piece by piece. First decide which piece is active where. Then test the joins, one at a time. On WTA20 you got Q5 wrong and Q4 partly right. This pattern had not shown up before, so it is new.

Worked example · the exact problem you saw

Consider f: (0, 2) → R, f(x) = x/2 + 2/x and g(x) = min{f(t) : 0 < t ≤ x} for 0 < x ≤ 1, g(x) = 3/2 + x for 1 < x < 2. Then: (A) g is continuous but not differentiable at x = 1. (B) g is not continuous for all x ∈ (0, 2). (C) g is neither continuous nor differentiable at x = 1. (D) g is continuous and differentiable for all x ∈ (0, 2).

You marked B and C. Correct: A (by my working; the portal does not print the key). Here's why.

Step 1 · what the running minimum is f'(x) = 1/2 − 2/x² = (x² − 4)/(2x²), which is negative on (0, 2). So f is decreasing there, and the smallest value of f(t) for t ≤ x is the last one, f(x). Hence g(x) = x/2 + 2/x on (0, 1].
Step 2 · the value at the join g(1) = 1/2 + 2 = 5/2.
Step 3 · continuity at 1 The right piece at 1 gives 3/2 + 1 = 5/2. Left limit = g(1) = right limit = 5/2, so g is continuous at 1. Options B and C both say it is not, so both are out. B also says "for all x", which is far too strong.
Step 4 · slopes at 1 Left: g'(1⁻) = f'(1) = 1/2 − 2 = −3/2. Right: g'(1⁺) = 1. They are different, so g is not differentiable at 1. Option D is out.
Step 5 · answer Only A: continuous, not differentiable at 1. Check the sketch below: the curve and the line meet at one point, with a corner.
Answer: A

The shortcuts
  • Sketch first. A rough sketch shows where pieces switch. Do it before reading the options.
  • Running minimum g(x) = min{f(t) : t ≤ x}. Where f is decreasing, g = f. Where f dips and then rises, g follows f down to the lowest point and stays flat after it.
  • The joins are continuous. The only question is the slope. At a smooth lowest point both slopes are 0, so the running minimum is differentiable there.
  • max{p, q} changes piece only where p = q. A kink can only be there, and only if the slopes differ.
  • Inverse trig: sin⁻¹(sin x) ≤ cos⁻¹(cos x) for every x. So max{sin⁻¹(sin x), cos⁻¹(cos x)} = cos⁻¹(cos x), and max{sin⁻¹(cos x), cos⁻¹(sin x)} = π/2 − sin⁻¹(sin x).

3 · Series expansion: find a and b, then the limit

LimitsCame backSat · WTA20

Worked example · the exact problem you saw

If lim (x→0) [1/(sin²x · ln(1+x))] · (1/√(1+x) − (1+ax)/(1+bx)) = ℓ and g(x) = ( (1+x)^(1/(2ax)) / e² )^(3/(b sin x)) (a, b real constants, ℓ ∈ R − {0}). Q15: the value of ℓ is (A) −1/32 (B) −3/32 (C) −1/16 (D) 1/32. Q16: lim (x→0) g(x) is (A) e^(−1/(8ℓ)) (B) e^(1/(8ℓ)) (C) e^(−1/(4ℓ)) (D) e^(1/(4ℓ)).

Step 1 · decide the order The bottom is sin²x · ln(1+x) ≈ x² · x = x³. It is a product, so first terms are enough there. The top must be known to x³, and for a finite nonzero limit its x and x² coefficients must be 0.
Step 2 · expand the root (1+x)^(−1/2) = 1 − x/2 + 3x²/8 − 5x³/16 + … (Maclaurin series).
Step 3 · expand the fraction 1/(1+bx) = 1 − bx + b²x² − b³x³ + …. Multiply by (1+ax): (1+ax)/(1+bx) = 1 + (a−b)x − b(a−b)x² + b²(a−b)x³ + ….

Step 5 · the limit, Q15 Coefficient of x³ in the top: −5/16 − b²(a−b) = −5/16 − (9/16)(−1/2) = −5/16 + 9/32 = −1/32. The bottom is x³, so ℓ = −1/32. That is option A.
Step 6 · Q16: take the log With a = 1/4, b = 3/4: 1/(2a) = 2 and 3/b = 4. ln g = (4/sin x)(2 ln(1+x)/x − 2) = (8/sin x)(ln(1+x) − x)/x. Use ln(1+x) − x ≈ −x²/2: ln g ≈ (8/x)(−x/2) = −4. So g → e⁻⁴.
Step 7 · match the option With ℓ = −1/32, 8ℓ = −1/4 and 1/(8ℓ) = −4. So e⁻⁴ = e^(1/(8ℓ)), which is option B.
Answer: Q15 A (−1/32), Q16 B (e^(1/(8ℓ)) = e⁻⁴)

The shortcuts
  • Match the order. If the bottom is xⁿ, expand every term of the top to xⁿ. For a finite limit the coefficients of x⁰ … xⁿ⁻¹ must be 0. Each zero coefficient is one equation for a constant.
  • Expand a fraction (1+ax)/(1+bx) as (1+ax)(1 − bx + b²x² − b³x³ + …). The pattern is 1 + (a−b)x − b(a−b)x² + b²(a−b)x³.
  • Keep these ready: (1+x)^(−1/2) = 1 − x/2 + 3x²/8 − 5x³/16, ln(1+x) = x − x²/2 + x³/3 − x⁴/4.
  • A 1^∞ form: take the log, expand it, and then exponentiate. Do not guess the form.
  • Do not skip because it looks long. Write the setup first (order, equations), and see how short it is.

Worked example · the exact problem you saw

For n ∈ N, define Pₙ = ∏ (k=1..n) (k⁴ + 4)/(k² + 1)². Evaluate lim (n→∞) n²(2Pₙ − 1 − 2/n).

Your answer was 4. Correct answer: 1. Here's why.

Step 1 · factor the top k⁴ + 4 = (k² + 2)² − (2k)² = (k² − 2k + 2)(k² + 2k + 2). Since k² − 2k + 2 = (k−1)² + 1 and k² + 2k + 2 = (k+1)² + 1, the top is ((k−1)² + 1)((k+1)² + 1).
Step 2 · name the repeating piece Let uₖ = k² + 1. Each term is u(k−1) · u(k+1) / uₖ².
Step 3 · split into two telescoping products ∏ u(k−1)/uₖ = u₀/uₙ = 1/(n² + 1). And ∏ u(k+1)/uₖ = u(n+1)/u₁ = ((n+1)² + 1)/2. Keep the end terms: u₀ = 1 and u₁ = 2 set the constants.
Step 4 · closed form Pₙ = (n² + 2n + 2) / (2(n² + 1)). Test with n = 1: the definition gives (1⁴+4)/(1²+1)² = 5/4 and the formula gives 5/(2·2) = 5/4. ✓
Step 5 · subtract the first two terms 2Pₙ = 1 + (2n+1)/(n²+1). So 2Pₙ − 1 − 2/n = (2n+1)/(n²+1) − 2/n = (n − 2)/(n(n² + 1)). The 1 and the 2/n are the first two terms, so what is left is of size 1/n².
Step 6 · the limit n² · (n − 2)/(n(n² + 1)) = n(n − 2)/(n² + 1) → 1.
Answer: 1
I can't see your working. Two checks catch most slips here: test the closed form at n = 1, and notice that the limit asks for the coefficient of 1/n², which is why the 1 and the 2/n are subtracted first.

The shortcuts
  • Factor first. Look for a difference of squares or a sum or difference of cubes that leaves factors at shifted indices: k⁴+4 = ((k−1)²+1)((k+1)²+1), k³−1 = (k−1)(k²+k+1).
  • Name the repeating piece uₖ. Each term becomes u(k−1)/uₖ or u(k+1)/uₖ, and the product telescopes: ∏ u(k−1)/uₖ = u₀/uₙ.
  • Keep the end terms. They set the constant in the closed form.
  • Closed form first, limit second. If the limit subtracts the leading terms, the answer sits one order further out.
  • Test the closed form at n = 1 or n = 2 before you use it.

Answer: D · 5
  1. The bottom is x⁴. For a finite limit the top must have zero coefficients for x, x², x³.
  2. ln(1+x) = x − x²/2 + x³/3 − x⁴/4 + ….
  3. 1/(1+bx) = 1 − bx + b²x² − b³x³ + …, so x(1+ax)/(1+bx) = x + (a−b)x² − b(a−b)x³ + b²(a−b)x⁴ + ….
  4. x terms match. x²: −1/2 = a − b.
  5. x³: 1/3 = −b(a−b) = b/2, so b = 2/3 and a = 1/6.
  6. x⁴: ln gives −1/4. The fraction gives b²(a−b) = (4/9)(−1/2) = −2/9. The top is (−1/4 − (−2/9))x⁴ = −x⁴/36, so ℓ = −1/36.
  7. 12a + 6b + 36ℓ = 2 + 4 − 1 = 5.
  • A (−3): forgot that the fraction also has an x⁴ term, took ℓ = −1/4: 2 + 4 − 9
  • B (7): subtracted the other way round, ℓ = +1/36: 2 + 4 + 1
  • C (8): solved the two equations with a and b interchanged, a = 2/3, b = 1/6: 8 + 1 − 1

For n ≥ 2, let Pₙ = ∏ (k=2..n) (k³ − 1)/(k³ + 1). Then lim (n→∞) n³(3Pₙ − 2 − 2/n²) equals:

Pick one option.

Answer: A · −2
  1. Factor: k³ − 1 = (k − 1)(k² + k + 1) and k³ + 1 = (k + 1)(k² − k + 1).
  2. Let uₖ = k² + k + 1. Then k² − k + 1 = u(k−1). Each term is [(k−1)/(k+1)] · [uₖ/u(k−1)].
  3. ∏ (k=2..n) (k−1)/(k+1) = (1·2)/(n(n+1)) = 2/(n(n+1)).
  4. ∏ (k=2..n) uₖ/u(k−1) = uₙ/u₁ = (n² + n + 1)/3.
  5. Pₙ = 2(n² + n + 1)/(3n(n+1)). Check n = 2: 2·7/(3·6) = 7/9 and the definition gives 7/9. ✓
  6. 3Pₙ = 2 + 2/(n(n+1)), so 3Pₙ − 2 − 2/n² = 2/(n(n+1)) − 2/n² = −2/(n²(n+1)).
  7. n³ · (−2)/(n²(n+1)) = −2n/(n+1) → −2.

  • C (0): used Pₙ → 2/3 and decided the bracket tends to 0, without keeping the next term
  • D (diverges): dropped the end terms of the telescoping (the 2 and the 3), so 3Pₙ no longer tends to 2 and the bracket tends to 1

Let f(x) = 2 − x² and g(y) = [y] + sin(πy/2) for 0 ≤ y ≤ 2, where [·] is the greatest integer function. Then lim (x→1⁺) (g(f(x)) − 1)/(x − 1)² equals:

Pick one option.

Answer: B · −π²/2
  1. As x → 1⁺, y = f(x) = 2 − x² goes to 1 from below, so 0 ≤ y < 1.
  2. For 0 ≤ y < 1, [y] = 0, so g(y) = sin(πy/2).
  3. Put t = 1 − y > 0. Then g − 1 = sin(π/2 − πt/2) − 1 = cos(πt/2) − 1 ≈ −π²t²/8.
  4. t = 1 − y = x² − 1 = (x − 1)(x + 1), and x + 1 → 2, so t ≈ 2(x − 1).
  5. t² ≈ 4(x − 1)².
  6. (g − 1)/(x − 1)² ≈ −(π²/8) · 4 = −π²/2.
  • A (−π²/8): wrote t ≈ x − 1 and forgot the factor x + 1 ≈ 2, so t² ≈ 4(x−1)² became (x−1)²
  • C (0): stopped at the first order. The slope of sin at its top is 0, so the first-order term vanishes, but the second-order term does not
  • D (+∞): used the branch y > 1 (where [y] = 1) because x → 1⁺ "feels like" y → 1⁺. Here the inner function runs the other way

Let f(x) = x² sin(1/x) for x ≠ 0 and f(0) = 0. Select all correct statements.

Select every correct option. It counts only if your set matches exactly.

Answer: A, B, D
  1. A: |f(x)| ≤ x² → 0 = f(0) by the squeeze theorem, so f is continuous at 0. True.
  2. B: (f(h) − f(0))/h = h sin(1/h), and |h sin(1/h)| ≤ |h| → 0. So f'(0) = 0. True.
  3. For x ≠ 0: f'(x) = 2x sin(1/x) + x² cos(1/x) · (−1/x²) = 2x sin(1/x) − cos(1/x).
  4. C: as x → 0, 2x sin(1/x) → 0 but cos(1/x) keeps swinging between −1 and 1 (it equals 1 at x = 1/(2πk) and −1 at x = 1/((2k+1)π)). So lim f'(x) does not exist. False, even though f'(0) exists.
  5. D: |f'(x)| ≤ 2|x| + 1 < 3 on (−1, 1) for x ≠ 0, and f'(0) = 0. Bounded. True.
  6. Write T, T, F, T beside A, B, C, D. The set is A, B, D.
  • C ticked: assumed that if f' exists at every point then f' must be continuous. It need not be
  • D not ticked: felt that an oscillating f' must be unbounded. cos(1/x) oscillates but stays between −1 and 1
  • B not ticked: stopped at the formula for f'(x) and did not check x = 0 with the definition
