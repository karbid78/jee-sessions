The shortcuts
  • Follow-through rule: when you prove one fact, write down what else it gives before you look at the options. Then test every option. A "true" needs a proof. A "false" needs one counterexample.
  • For a 3×3, adj(adj M) = (det M)·M. Also adj M = (det M)·M⁻¹, and M·adj M = (det M)·I.
  • Equal row sums or column sums in a determinant: add all columns into the first column, factor out the common sum, then subtract rows to clear zeros. Your CTA17 Q14: every row sums to 2(a+b+c), and the determinant is 2(a+b+c)³. So k = 2, α = β = γ = 1, and (2α+β+γ)^k = 4² = 16. You wrote 1024.
Worked example · the exact problem you saw

M is a 3×3 invertible real matrix with M⁻¹ = adj(adj M). Which of these are ALWAYS true? (A) M = I (B) (adj M)² = I (C) M² = I (D) det M = 1

Your answer: D only. Correct answer: B, C and D.

Step 1 · use the adj(adj M) ruleFor a 3×3, adj(adj M) = (det M)·M. Write d = det M. The condition M⁻¹ = adj(adj M) becomes
M⁻¹ = d·M
Step 2 · take determinantsdet(M⁻¹) = 1/d det(d·M) = d³·d = d⁴ So 1/d = d⁴, which gives d⁵ = 1. M is real, so d is real, so d = 1. Option D is true. This is where you stopped.
Step 3 · keep going with d = 1Now M⁻¹ = 1·M = M. Multiply both sides by M:
M² = I Option C is true.
Step 4 · the adjointadj M = d·M⁻¹ = M⁻¹ = M. So (adj M)² = M² = I. Option B is true.
Step 5 · is M forced to be I?No. Take M = diag(1, −1, −1). Its det is 1, M² = I, M⁻¹ = M, and adj(adj M) = 1·M = M. It meets the condition but M ≠ I. Option A is false.

The trap: stopping after the first true fact. Once you know M⁻¹ = M, three options fall out in one line each. Ask "what else does this give me?" before you move on.

The shortcuts
  • Modulus: find where the sign changes first. List the sign of every term before you add. A negative term under |·| counts as plus, not zero and not minus.
  • Least common term: the common terms of AP(a1; d1) and AP(a2; d2) form an AP with d = lcm(d1, d2). Combine the remainder conditions two at a time, then check that your number is really a term of each AP. Give the least one.
  • Alternating arithmetico-geometric series: write the sum as Σ n²·y^(n−1) and use (1+y)/(1−y)³ for |y| < 1. The alternating sign is just a negative y.
  • Telescoping split: for k ≥ 3, (k−1)(k−2)/(k−1)! = 1/(k−3)!. Split the polynomial so that each piece cancels its neighbour.
Worked example · the exact problem you saw

For k = 1, 2, …, 100, S_k is the sum of the infinite GP with first term (k−1)/k! and common ratio 1/k. Find 100²/100! + Σ |(k²−3k+1)·S_k|, summed for k = 1 to 100.

Your answer: 2. Correct answer: 3.

Step 1 · sum each GPFor k ≥ 2: S_k = first term / (1 − ratio) = [(k−1)/k!] / [(k−1)/k] = k/k! = 1/(k−1)!. For k = 1 the first term is 0, so every term is 0 and S_1 = 0.
Step 2 · check the sign of the multiplierk²−3k+1 is −1 at k = 2, and it is 1 at k = 3 and positive after that. Only k = 2 is negative. Under the modulus the k = 2 term counts as
|−1 × S_2| = |−1 × 1| = 1 This is the term that went missing: your 2 is 1 short of 3.
Step 3 · split the multiplier so it telescopesFor k ≥ 3: k²−3k+1 = (k−1)(k−2) − 1. So
(k²−3k+1)·S_k = 1/(k−3)! − 1/(k−1)!
Step 4 · add k = 3 to 100The first parts give 1/0! + 1/1! + … + 1/97!. The second parts give 1/2! + … + 1/99!. Everything from 1/2! to 1/97! cancels. What is left:
1/0! + 1/1! − 1/98! − 1/99! = 2 − 1/98! − 1/99!
Step 5 · assembleTotal of the modulus sum = 1 (from k = 2) + 2 − 1/98! − 1/99!. Now 1/98! + 1/99! = (99 + 1)/99! = 100/99! = 100²/100!. That is exactly the extra term in the question, so the two cancel.
Answer: 3
The trap: reading |…| as "ignore the negative ones". The modulus turns the k = 2 term into +1. List the sign of every term before you add.

3 · A line through a triangle: find the interval

Coordinate geometrySeen in CTA17

In CTA17 Q13 you answered 2.19 and the key is 33/14 = 2.357. That is a near miss, so the method was probably right and one intersection went wrong. I only have your answer, not your working, so I can't tell which one. A routine that lets you check each crossing is the fix.

Ask Claude about this pattern ↗Opens a claude.ai chat about this pattern
The shortcuts
  • Turn the point into a line. The point (l, l+1) slides along y = x + 1. The question is: for which x-values is that line inside the triangle?
  • Intersect with each side, then check the segment. Write each side as a line, intersect it with yours, and keep a crossing only if it lies between the two vertices. A line meets a triangle's boundary in two points. The third crossing lands outside its segment.
  • Or use three inequalities. Each side gives one. Test the centroid to choose the direction. The answer is where all three overlap.
  • Keep fractions. Subtract q − p over a common denominator. Then test one number in the middle of the interval.
Worked example · the exact problem you saw

The point (l, l+1) lies strictly inside the triangle with vertices A(0, 3), B(−2, 0), C(6, 1), for l in (p, q). Find q − p.

Your answer: 2.19. Correct answer: 33/14 ≈ 2.357.

Step 1 · turn the point into a lineThe point (l, l+1) has y = x + 1, so it slides along the line y = x + 1. We need the stretch of that line that is strictly inside triangle ABC.
Step 2 · write the three sidesAB: y = 3(x+2)/2 BC: y = (x+2)/8 AC: y = 3 − x/3 Check each with its two vertices. AB gives 3 at x = 0 and 0 at x = −2. BC gives 0 at x = −2 and 1 at x = 6. AC gives 3 at x = 0 and 1 at x = 6.
Step 3 · intersect with y = x + 1, then check the segmentAB: x + 1 = 3(x+2)/2 gives x = −4. AB runs from x = −2 to 0, so this is off the segment. The line never crosses AB.
BC: x + 1 = (x+2)/8 gives 8x + 8 = x + 2, so x = −6/7. It is between −2 and 6. ✓
AC: x + 1 = 3 − x/3 gives 4x/3 = 2, so x = 3/2. It is between 0 and 6. ✓
Step 4 · check the middleBetween x = −6/7 and x = 3/2 the line is inside. Test l = 0, the point (0, 1). It is above BC (1 > 2/8), below AC (1 < 3), and below AB (1 < 3), the same side as C. So it is inside, and the interval is (−6/7, 3/2).
Step 5 · subtract with fractionsq − p = 3/2 − (−6/7) = 3/2 + 6/7 = 21/14 + 12/14 = 33/14 ≈ 2.357
Answer: 33/14
The trap: the third crossing. AB gives x = −4, which is a crossing of the extended side, not of the triangle. A crossing outside its segment does not count.

4 · Limits with unknown constants: expand and match

LimitsSeen in CTA18

In CTA18 Q17 you skipped a limit in 23 seconds. It looks scary because of the letters a and b and the unknown f(x). It is really two matching equations. Expand the top as a series, make the low powers vanish, and let the last power equal the limit.

Ask Claude about this pattern ↗Opens a claude.ai chat about this pattern
The shortcuts
  • Match the order. If the bottom is xⁿ, expand the top to the xⁿ term. For a finite limit every lower power must have coefficient 0. The xⁿ coefficient is the limit.
  • If f(x)/x → 1, then f(x)ⁿ behaves like xⁿ. Replace f(x)³ by x³: N/f³ = (N/x³)·(x/f)³, and (x/f)³ → 1.
  • Expansions to know: sin x = x − x³/6 + x⁵/120, cos x = 1 − x²/2 + x⁴/24, so x cos x = x − x³/2 + x⁵/24.
  • Count the conditions. A numerator made of x, x cos x and sin x has only odd powers. Bottom x³ gives one vanishing condition and one matching equation. Bottom x⁵ gives two vanishing conditions and one matching equation.
Worked example · the exact problem you saw

lim(x→0) f(x)/x = 1, and lim(x→0) [x(1 + a cos x) − b sin x] / f(x)³ = 1. Find b/a.

Your answer: none (I skipped it in 23 seconds). Correct answer: 0.6.

Step 1 · replace f(x)³ by x³Since f(x)/x → 1, the limit is unchanged if we divide by x³ instead of f(x)³. So we need
lim [x + a·x cos x − b sin x] / x³ = 1
Step 2 · expand the top to x³x + a(x − x³/2 + …) − b(x − x³/6 + …) Collect the powers of x:
(1 + a − b)·x + (−a/2 + b/6)·x³ + …
Step 3 · two conditionsThe bottom is x³. If the x coefficient is not 0, the ratio blows up. So 1 + a − b = 0. Then the ratio tends to the x³ coefficient, which must be 1:
1 + a − b = 0 and −a/2 + b/6 = 1
Step 4 · solveFrom the first, b = 1 + a. Put that in the second and multiply by 6: −3a + 1 + a = 6, so −2a = 5 and a = −5/2. Then b = −3/2.
b/a = (−3/2)/(−5/2) = 3/5 = 0.6
Step 5 · cross-check with L'HôpitalLet N(x) = x + a·x cos x − b sin x. N'(0) = 1 + a − b. N''(0) = 0 for free. N'''(x) = −3a cos x + a x sin x + b cos x, so N'''(0) = −3a + b. Three derivatives of x³ give 6, so N'''(0)/6 = 1 gives −3a + b = 6. That is the second equation times 6.
Answer: b/a = 0.6
The trap: skipping because there is no visible number to plug in. When a limit has unknown constants and a power of x below, the answer is always "kill the low powers, match the last one".
