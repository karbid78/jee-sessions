1 · Counting solutions of trig equations

TrigonometryCame back

You need this on almost every Sunday paper. The count depends on two things: which values the equation can actually take, and how many angles give each value. Missing one boundary value or one option changes the whole answer.

Worked example · the exact problem you saw

If n is the number of solutions of tan(5π cosθ) = cot(5π sinθ), θ ∈ (0, 2π), find n − 20.

Your answer was 4. Correct answer: 8 (so n = 28).

Step 1 · turn cot into tan Write cot B = tan(π/2 − B). The equation becomes tan(5π cosθ) = tan(π/2 − 5π sinθ). Two tangents are equal when the angles differ by a multiple of π.
Step 2 · get one linear equation 5π cosθ = π/2 − 5π sinθ + nπDivide by 5π:cosθ + sinθ = (2n+1)/10
Step 3 · what values can cosθ + sinθ take? cosθ + sinθ = √2 sin(θ+π/4), so it lies in [−√2, √2] ≈ [−1.414, 1.414]. The bound is √2, not 1.|2n+1|/10 ≤ 1.414 ⟹ |2n+1| ≤ 14.14So 2n+1 can be any odd number from −13 to 13: ±1, ±3, ±5, ±7, ±9, ±11, ±13. That is 14 values of k. Write them out. Do not stop at ±11.
Step 4 · 2 angles per value For each k with |k| < √2, √2 sin(θ+π/4) = k has 2 solutions in a full turn. The special case is k = ±1, where θ = 0 and θ = 2π land on the excluded ends. Here k = ±1 would need 2n+1 = ±10, which is even, so it never happens.14 values × 2 = 28
Step 5 · are tan and cot defined? A "solution" is spoiled if tan or cot is undefined. That needs 5π cosθ = π/2 + mπ, so cosθ = (2m+1)/10, and then also sinθ = j/5. Then (2m+1)² + 4j² = 100. But (2m+1)² is odd and 4j² is even, so the left side is odd while 100 is even. That is impossible, so none are spoiled. n = 28, n − 20 = 8
Answer: 8
The trap: stopping the list of odd numbers early. Whenever a bound like |2n+1| ≤ 14.14 appears, write the values out and check the last one against √2.

The shortcuts
  • tan = cot, or sin = cos: turn it into one linear equation in the angles. It usually ends as cosθ ± sinθ = k.
  • cosθ ± sinθ ranges over [−√2, √2], not [−1, 1]. Each interior k gives 2 angles in a full turn. Check k = ±1 if the interval is open at 0 and 2π.
  • Parameter questions: isolate m as a function of s = sin x. Sketch it on [−1, 1]. Then count x-values per s: for x in [0, 2π], s in (−1,1) with s≠0 gives 2, s = ±1 gives 1, and s = 0 gives 3 (0, π, 2π).
  • Multi-correct: test every option before you lock in. Your CTA18 Q11 is the example below.
Your CTA18 Q11, solved: m sin²x + (m−1) sin x + (m−2) = 0 gives m = (s+2)/(s²+s+1). On [−1, 1] this is 1 at s = ±1, 2 at s = 0, and peaks at 1 + 2/√3 at s = √3 − 2. TrigonometryCame back

The test gives you the tell: a step of 2 in the angles, a symmetric range around 90°, a product with 3k in it, or a ratio of sines.

Worked example · the exact problem you saw

Let α = 1/(sin60° sin61°) + 1/(sin62° sin63°) + … + 1/(sin118° sin119°). Find (cosec 1° / α)².

Your answer was 1. Correct answer: 3.

Step 1 · the identity cot n − cot(n+1) = sin1° / (sin n · sin(n+1))So 1/(sin n sin(n+1)) = (cot n − cot(n+1)) / sin1°. Every term of α has this shape.
Step 2 · write the sum out The angles start at 60 and jump by 2: n = 60, 62, …, 118 (30 terms).sin1°·α = (cot60 − cot61) + (cot62 − cot63) + … + (cot118 − cot119)This is not an ordinary telescope, because cot61 is never followed by a +cot61. The cancellation comes from somewhere else.

The positive terms are cot60, cot62, …, cot118. Pair 62 with 118, 64 with 116, …, 88 with 92: each pair sums to 0. The middle one is cot90° = 0. Only cot60° has no partner (its partner would be cot120°, which isn't in the list).

The trap: treating it as "everything cancels except the ends", which gives a clean-looking but wrong number. A step of 2, or a range symmetric about 90°, means the cancellation comes from cot(180°−x) = −cot x.

Three identities to recognise on sight
  • Cot difference: 1/(sin a · sin(a+d)) = (cot a − cot(a+d)) / sin d. Then look for pairing with cot(180°−x) = −cot x.
  • Product with 3k: 1 + 2cosθ = sin(3θ/2)/sin(θ/2) and 1 − 2cosθ = −cos(3θ/2)/cos(θ/2). The product over θ, 3θ, 9θ, … telescopes. Your CTA16 Q8: the five factors collapse to −cos(243π/22)/cos(π/22) = 1, so α = 1 and 5 − α² = 4.
  • Ratio of sines: if p·sinα = q·sinβ, then (sinα + sinβ)/(sinα − sinβ) = (q+p)/(q−p) and this equals tan((α+β)/2) / tan((α−β)/2). Your CTA17 Q12: (29+19)/(29−19) = 4.8.

Inverse trigCame back

Step 3 · solve for y Now v = 0: y² + 2xy = y(y+2x) = 0. This gives (0,0), (1,0), (1,−2), (−1,0), (−1,2). Five candidates from E₁.

Four moves for inverse-trig questions
  • sin⁻¹A + cos⁻¹B = π/2 means A = B (with |A| ≤ 1). Likewise tan⁻¹A + cot⁻¹B = π/2 means A = B.
  • Telescoping: tan⁻¹(1/(1 + k(k+1))) = tan⁻¹(k+1) − tan⁻¹k. Check that each denominator has the form k²+k+1: 3, 7, 13, 21, … are k = 1, 2, 3, 4.
  • Range: cot⁻¹(−x) = π − cot⁻¹x, because cot⁻¹ lives in (0, π). Watch when a sum of tan⁻¹ terms crosses 1 in product: you add π.
  • "x, y integers": first use the bounds |argument| ≤ 1 to shrink to a handful of values, then test them.

Two rules
  • Domain of a sum of pieces: solve each condition alone, draw a number line, then intersect. For a periodic condition, list only the windows that touch the interval. Your Q9: 7x − x² − 6 ≥ 0 gives [1, 6]; sin x + cos x ≥ 0 gives [−π/4, 3π/4] + 2πn. The windows that touch [1, 6] are [1, 3π/4] and [7π/4, 6]. Sum = 7 + 5π/2 ≈ 14.85.
  • Piecewise function questions: find where each piece lands, then run one number through f twice. If it comes back, f is an involution. That settles "invertible", "own inverse" and "many-one" at once.

The shortcut
  • Swapped-root systems: Vieta for both, express the leftover letters, plug the shared root into its own equation, subtract, cancel the non-zero difference. In general, for x² − pax − qb and x² − pcx − qd, you get a + c = q(p + 1) and the total is pq(p+1).
  • Sign facts first: x² − |α|x − |β| = 0 has a product ≤ 0, so its roots are on opposite sides of 0. The one with bigger magnitude is positive.
Your skipped CTA18 Q13, solved (my derivation; the portal didn't show the key): the roots a, b have a + b = |α| ≥ 0 and ab ≤ 0, and |a| < |b|, so b > 0 and a = |α| − b < −1 (using 1+|α| < b). Then log_|a|((x/b)²) = 1 gives x = ±b√|a|. Since |a| > 1, the positive root exceeds b: one root in (b, ∞). Since b > |a| > √|a|, the negative root is below a: one root in (−∞, a). Nothing in (a, b). So A, B and D are correct; C is not.
