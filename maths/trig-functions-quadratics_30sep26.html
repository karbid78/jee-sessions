1 · Counting solutions of trig equations

You need this on almost every Sunday paper. The count depends on two things: which values the equation can actually take, and how many angles give each value. Missing one boundary value or one option changes the whole answer.

Worked example · the exact problem you saw

If n is the number of solutions of tan(5π cosθ) = cot(5π sinθ), θ ∈ (0, 2π), find n − 20.

Your answer was 4. Correct answer: 8 (so n = 28).

Step 1 · turn cot into tan Write cot B = tan(π/2 − B). The equation becomes tan(5π cosθ) = tan(π/2 − 5π sinθ). Two tangents are equal when the angles differ by a multiple of π.
Step 2 · get one linear equation 5π cosθ = π/2 − 5π sinθ + nπDivide by 5π:cosθ + sinθ = (2n+1)/10
Step 3 · what values can cosθ + sinθ take? cosθ + sinθ = √2 sin(θ+π/4), so it lies in [−√2, √2] ≈ [−1.414, 1.414]. The bound is √2, not 1.|2n+1|/10 ≤ 1.414 ⟹ |2n+1| ≤ 14.14So 2n+1 can be any odd number from −13 to 13: ±1, ±3, ±5, ±7, ±9, ±11, ±13. That is 14 values of k. Write them out. Do not stop at ±11.
Step 4 · 2 angles per value For each k with |k| < √2, √2 sin(θ+π/4) = k has 2 solutions in a full turn. The special case is k = ±1, where θ = 0 and θ = 2π land on the excluded ends. Here k = ±1 would need 2n+1 = ±10, which is even, so it never happens.14 values × 2 = 28
Step 5 · are tan and cot defined? A "solution" is spoiled if tan or cot is undefined. That needs 5π cosθ = π/2 + mπ, so cosθ = (2m+1)/10, and then also sinθ = j/5. Then (2m+1)² + 4j² = 100. But (2m+1)² is odd and 4j² is even, so the left side is odd while 100 is even. That is impossible, so none are spoiled. n = 28, n − 20 = 8
Answer: 8
The trap: stopping the list of odd numbers early. Whenever a bound like |2n+1| ≤ 14.14 appears, write the values out and check the last one against √2.

The shortcuts
  • tan = cot, or sin = cos: turn it into one linear equation in the angles. It usually ends as cosθ ± sinθ = k.
  • cosθ ± sinθ ranges over [−√2, √2], not [−1, 1]. Each interior k gives 2 angles in a full turn. Check k = ±1 if the interval is open at 0 and 2π.
  • Parameter questions: isolate m as a function of s = sin x. Sketch it on [−1, 1]. Then count x-values per s: for x in [0, 2π], s in (−1,1) with s≠0 gives 2, s = ±1 gives 1, and s = 0 gives 3 (0, π, 2π).
  • Multi-correct: test every option before you lock in. Your CTA18 Q11 is the example below.
Your CTA18 Q11, solved: m sin²x + (m−1) sin x + (m−2) = 0 gives m = (s+2)/(s²+s+1). On [−1, 1] this is 1 at s = ±1, 2 at s = 0, and peaks at 1 + 2/√3 at s = √3 − 2. Worked example · the exact problem you saw

Let α = 1/(sin60° sin61°) + 1/(sin62° sin63°) + … + 1/(sin118° sin119°). Find (cosec 1° / α)².

Your answer was 1. Correct answer: 3.

Step 2 · write the sum out The angles start at 60 and jump by 2: n = 60, 62, …, 118 (30 terms).sin1°·α = (cot60 − cot61) + (cot62 − cot63) + … + (cot118 − cot119)This is not an ordinary telescope, because cot61 is never followed by a +cot61. The cancellation comes from somewhere else.

The positive terms are cot60, cot62, …, cot118. Pair 62 with 118, 64 with 116, …, 88 with 92: each pair sums to 0. The middle one is cot90° = 0. Only cot60° has no partner (its partner would be cot120°, which isn't in the list).

Three identities to recognise on sight
  • Cot difference: 1/(sin a · sin(a+d)) = (cot a − cot(a+d)) / sin d. Then look for pairing with cot(180°−x) = −cot x.
  • Product with 3k: 1 + 2cosθ = sin(3θ/2)/sin(θ/2) and 1 − 2cosθ = −cos(3θ/2)/cos(θ/2). The product over θ, 3θ, 9θ, … telescopes. Your CTA16 Q8: the five factors collapse to −cos(243π/22)/cos(π/22) = 1, so α = 1 and 5 − α² = 4.
  • Ratio of sines: if p·sinα = q·sinβ, then (sinα + sinβ)/(sinα − sinβ) = (q+p)/(q−p) and this equals tan((α+β)/2) / tan((α−β)/2). Your CTA17 Q12: (29+19)/(29−19) = 4.8.

Four moves for inverse-trig questions
  • sin⁻¹A + cos⁻¹B = π/2 means A = B (with |A| ≤ 1). Likewise tan⁻¹A + cot⁻¹B = π/2 means A = B.
  • Telescoping: tan⁻¹(1/(1 + k(k+1))) = tan⁻¹(k+1) − tan⁻¹k. Check that each denominator has the form k²+k+1: 3, 7, 13, 21, … are k = 1, 2, 3, 4.

Two rules
  • Domain of a sum of pieces: solve each condition alone, draw a number line, then intersect. For a periodic condition, list only the windows that touch the interval. Your Q9: 7x − x² − 6 ≥ 0 gives [1, 6]; sin x + cos x ≥ 0 gives [−π/4, 3π/4] + 2πn. The windows that touch [1, 6] are [1, 3π/4] and [7π/4, 6]. Sum = 7 + 5π/2 ≈ 14.85.
  • Piecewise function questions: find where each piece lands, then run one number through f twice. If it comes back, f is an involution. That settles "invertible", "own inverse" and "many-one" at once.

The shortcut
  • Swapped-root systems: Vieta for both, express the leftover letters, plug the shared root into its own equation, subtract, cancel the non-zero difference. In general, for x² − pax − qb and x² − pcx − qd, you get a + c = q(p + 1) and the total is pq(p+1).
  • Sign facts first: x² − |α|x − |β| = 0 has a product ≤ 0, so its roots are on opposite sides of 0. The one with bigger magnitude is positive.
Your skipped CTA18 Q13, solved (my derivation; the portal didn't show the key): the roots a, b have a + b = |α| ≥ 0 and ab ≤ 0, and |a| < |b|, so b > 0 and a = |α| − b < −1 (using 1+|α| < b). The number of solutions of tan(3π cosθ) = cot(3π sinθ), θ ∈ (0, 2π), is:

2L4Trig root counting

For how many integers m with |m| ≤ 7 does m sin x = 1 + sin²x have exactly two distinct solutions in [0, 2π]?

Answer: 10
  1. Let s = sin x. If s = 0 the equation says 0 = 1, so s ≠ 0.
  2. Divide by s: m = s + 1/s, with s in [−1, 1] and s ≠ 0.
  3. For s in (0, 1], s + 1/s ≥ 2, with equality only at s = 1. For s in [−1, 0), s + 1/s ≤ −2. So |m| < 2 gives no solutions.
  4. m = ±2 means s = ±1: x = π/2 or 3π/2. That is only 1 solution, not 2.
  5. For m > 2, s + 1/s = m has two positive roots with product 1, so exactly one lies in (0, 1). For m < −2 exactly one lies in (−1, 0).
  6. That one s in (0, 1) or (−1, 0) gives 2 values of x in [0, 2π].
  7. So m ∈ {3, 4, 5, 6, 7} and {−3, …, −7}: 10 integers.
Trap: counting m = ±2. There s = ±1 gives one solution, not two.

Trap: turning tan⁻¹5 + tan⁻¹6 into one tan⁻¹ of (11/−29) as an angle. When ab > 1 the angle gains π. Taking tangents avoids this.

8L4Inverse trig

x, y are integers. How many ordered pairs satisfy both?
E₁: sin⁻¹(x² − 2x) + cos⁻¹(y² − 2y) = π/2
E₂: tan⁻¹(x² + 3y) + cot⁻¹(y² + 3x) = π/2

Answer: 3
  1. E₁: cos⁻¹v = π/2 − sin⁻¹v, so sin⁻¹u = sin⁻¹v with u = x²−2x and v = y²−2y. Hence u = v and both lie in [−1, 1].
  2. x² − 2x = (x−1)² − 1 ≤ 1 forces (x−1)² ≤ 2. For an integer x that gives x = 0, 1, 2, with u = 0, −1, 0.
  3. The same list works for y, with v = 0, −1, 0.
  4. u = v: value 0 gives x, y ∈ {0, 2}, 4 pairs. Value −1 gives (1, 1), 1 pair. Five candidates.
  5. E₂: cot⁻¹Q = π/2 − tan⁻¹P = cot⁻¹P, so P = Q, that is x² + 3y = y² + 3x.
  6. Test: (0,0): 0 = 0 ✓. (0,2): 6 vs 4 ✗. (2,0): 4 vs 6 ✗. (2,2): 10 = 10 ✓. (1,1): 4 = 4 ✓.
  7. Three pairs survive.
Trap: treating E₁ and E₂ as two hard equations. Each is one line of algebra, and "integers" cuts x and y to three values each.

9L4Inverse trig

All angles in radians, principal values. If sin⁻¹(sin 15) + cos⁻¹(cos 15) + tan⁻¹(tan 15) = a − bπ with integers a and b, find a + b.

Answer: 19
  1. Let θ = 15 − 4π ≈ 2.434, which lies in (π/2, π). Sine and cosine have period 2π and tangent has period π, so sin 15 = sinθ, cos 15 = cosθ, tan 15 = tanθ.
  2. sin⁻¹(sinθ): the range is [−π/2, π/2] and θ > π/2, so the answer is π − θ = 5π − 15.
  3. cos⁻¹(cosθ): the range is [0, π] and θ is inside it, so the answer is θ = 15 − 4π.
  4. tan⁻¹(tanθ): the range is (−π/2, π/2) and θ is in (π/2, 3π/2), so the answer is θ − π = 15 − 5π.
  5. Add: (5π − 15) + (15 − 4π) + (15 − 5π) = 15 − 4π.
  6. So a = 15, b = 4, and a + b = 19.
Trap: assuming sin⁻¹(sin x) = x. That is true only when x is already in the principal range.

The domain of y = √(sin x − cos x) + √(9x − x² − 8) is [p, q] ∪ [r, s]. Find p + q + r + s.

11L4Functions

Let D = ⋃ₖ(4k, 4k+4) − ⋃ₖ{4k+1} and f: D → D with f(x) = 3x + 1 − 8k on (4k, 4k+1) and f(x) = (x − 1 + 8k)/3 on (4k+1, 4k+4). How many of these are TRUE? (i) f is one-one (ii) f is onto D (iii) f(f(x)) = x for all x in D (iv) f is many-one

Answer: 3
  1. First piece: x = 4k + t with t in (0, 1) gives f(x) = 4k + 3t + 1, which lies in (4k+1, 4k+4).
  2. Second piece: x = 4k + u with u in (1, 4) gives f(x) = 4k + (u − 1)/3, which lies in (4k, 4k+1).
  3. The two images do not overlap and together fill D. So f is one-one (i true) and onto D (ii true), and not many-one (iv false).
  4. Involution: y = 4k + 3t + 1 is in (4k+1, 4k+4), so use the second rule: f(y) = 4k + (3t + 1 − 1)/3 = 4k + t = x. So (iii) is true.
  5. Number check: f(0.4) = 2.2 and f(2.2) = (2.2 − 1)/3 = 0.4.
  6. (i), (ii), (iii) are true and (iv) is false: 3.
Trap: checking only one-one and onto. Run one number through f twice: it settles (iii) in ten seconds.

Find the total length of the domain of y = √(2 sin x − 1) + √(16 − x²).

13L4Quadratics

x² − 6ax − 7b = 0 has roots c, d and x² − 6cx − 7d = 0 has roots a, b, with a ≠ c. Find a + b + c + d.

Answer: 294
  1. Vieta on the first: c + d = 6a, cd = −7b. On the second: a + b = 6c, ab = −7d.
  2. Solve the linear ones: b = 6c − a and d = 6a − c.
  3. c is a root of the first: c² − 6ac − 7b = 0. a is a root of the second: a² − 6ac − 7d = 0.
  4. Subtract: c² − a² − 7(b − d) = 0.
  5. b − d = (6c − a) − (6a − c) = 7(c − a).
  6. (c − a)(c + a) = 49(c − a). Since a ≠ c, divide: a + c = 49.
  7. a + b + c + d = (a + b) + (c + d) = 6c + 6a = 6 × 49 = 294.
Trap: solving for the roots directly. The condition a ≠ c is the hint that a division by (c − a) is coming.

For how many integers k are both roots of x² − 2(k+1)x + k² + k + 6 = 0 real and less than 10?

Answer: 3

  2. D = 4(k+1)² − 4(k² + k + 6) = 4(k − 5) ≥ 0, so k ≥ 5.
  3. Axis x = k + 1 < 10 gives k < 9.
  4. f(10) = 100 − 20(k+1) + k² + k + 6 = k² − 19k + 86 > 0, so k < (19 − √17)/2 ≈ 7.44 or k > 11.56.
  5. Combine: 5 ≤ k < 7.44 (the k < 9 condition is weaker). So k = 5, 6, 7.
  6. Boundary check: k = 8 gives f(10) = 64 − 152 + 86 = −2 < 0, so 10 sits between the roots. Rejected.
  7. Count = 3.

15L4Quadratics

x² − 8ax − 9b = 0 has roots c, d and x² − 8cx − 9d = 0 has roots a, b, with a ≠ c. Find ab + cd.

Answer: −5103
  1. Vieta: c + d = 8a, cd = −9b, a + b = 8c, ab = −9d.
  2. So ab + cd = −9d − 9b = −9(b + d).
  3. Solve the linear ones: b = 8c − a and d = 8a − c, so b + d = 7(a + c).
  4. Shared roots: c² − 8ac − 9b = 0 and a² − 8ac − 9d = 0. Subtract: c² − a² = 9(b − d).
  5. b − d = 9(c − a), so (c − a)(c + a) = 81(c − a). Since a ≠ c, a + c = 81.
  6. ab + cd = −9 × 7 × 81 = −5103.
Trap: asking for ab + cd and solving for a, b, c, d one by one. Reduce it to b + d first.
