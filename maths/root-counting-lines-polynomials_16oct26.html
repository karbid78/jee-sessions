1 · Counting trig roots: find the bound first

Worked example · the exact problem you saw

The number of values of x satisfying sec(π√(x³ − x + 1)) · sec(π√(25 − x²)) = −1 is

Your answer was 0. Correct answer: 2 (x = 3 and x = 5).

Step 1 · name the two roots and the domain Let A = √(x³ − x + 1) and B = √(25 − x²). The equation is sec(Aπ)·sec(Bπ) = −1, the same as cos(Aπ)·cos(Bπ) = −1. Real B needs −5 ≤ x ≤ 5. Real A needs x³ − x + 1 ≥ 0, which fails for x below about −1.32. Check: x = −3, −4, −5 give −23, −59, −119.
Step 2 · use the bound |cos| ≤ 1, so |cos(Aπ)·cos(Bπ)| ≤ 1. A product of exactly −1 forces |cos(Aπ)| = 1 and |cos(Bπ)| = 1, with opposite signs. |cos(tπ)| = 1 only when t is a whole number, and then cos(kπ) = (−1)^k. So A and B are whole numbers and (−1)^A · (−1)^B = −1, which means A + B is odd.
Step 3 · build the candidate list from the easy root B is a whole number from 0 to 5, so x² = 25 − B² is one of 25, 24, 21, 16, 9, 0. That gives x = ±5, ±√24, ±√21, ±4, ±3, 0. Only these can work.
Step 4 · test each candidate Irrational x (±√24, ±√21): A² = x(x² − 1) + 1 is irrational (for √24 it is 23√24 + 1). A whole A has a whole A², so these fail. Negative x (−3, −4, −5): radicand negative, out.x = 0: A = 1, B = 5, A + B = 6 (even) → product +1, no
x = 4: A² = 61, not a square → no
x = 3: A² = 25, A = 5, B = 4, A + B = 9 (odd) → cos5π·cos4π = −1 ✓
x = 5: A² = 121, A = 11, B = 0, A + B = 11 (odd) → cos11π·cos0 = −1 ✓

The shortcuts
  • Product of two cosines (or secants) equal to ±1: each must be ±1. Then each angle is a whole multiple of π and cos(kπ) = (−1)^k.
  • The sign becomes parity. Product −1 means A + B odd. Product +1 means A + B even. Always test parity: it removes candidates that pass the bound.
  • Build the list from the easier factor (here B), then test each candidate in the harder one.
  • Domain first. Every radicand must be ≥ 0. A radicand of exactly 0 is allowed: cos 0 = 1.
  • If A is a whole number then A² is a whole number, so an irrational radicand fails at once.
  • Same idea elsewhere: sin x + cos y = 2 needs both at their maximum; |sin x| + |cos y| = 2 needs both at size 1.

2 · Counting roots with a derivative, not a sketch

FunctionsNew this time

Roots of f(x) = g(x) are the zeros of one function h = f − g. If h' never changes sign, h is steadily rising or falling and has at most one zero. Two curves sketched by eye can look as if they cross twice when they cross once.

Worked example · the exact problem you saw

The number of distinct real roots of e^(2x+1) − x² = (√3 cos20° − sin40°) / cos10° is

Your answer was 2. Correct answer: 1.

Step 1 · evaluate the trig constant √3 cos20° = 2 cos30° cos20° = cos50° + cos10° (product to sum: 2 cosA cosB = cos(A+B) + cos(A−B)). Also sin40° = cos50°. So the top is cos50° + cos10° − cos50° = cos10°, and the right side is cos10° / cos10° = 1. Numeric check: 1.7321 × 0.9397 − 0.6428 = 0.9848 = cos10°.
Step 2 · make one function The equation is e^(2x+1) − x² = 1. Let h(x) = e^(2x+1) − x² − 1. Roots of the equation are zeros of h.
Step 3 · differentiate and test the sign h'(x) = 2e^(2x+1) − 2x = 2(e^(2x+1) − x). If x ≤ 0: e^(2x+1) > 0 and −x ≥ 0, so the bracket is positive. If x > 0: e^t ≥ t + 1 for all t, so e^(2x+1) ≥ 2x + 2 > x. Either way h'(x) > 0: h is strictly increasing.
Step 4 · check the two ends As x → −∞: e^(2x+1) → 0, so h ≈ −x² − 1 → −∞. As x → +∞: the exponential beats x², so h → +∞. Test values: h(−1) = e^(−1) − 2 ≈ −1.63 and h(0) = e − 1 ≈ 1.72.A continuous, strictly increasing function from −∞ to +∞ crosses zero exactly once, near x ≈ -0.42.
Answer: 1
The trap: deciding from a rough sketch of e^(2x+1) against x² + 1. The derivative settles it in one line: h' > 0 everywhere, so one root.

The shortcuts
  • Evaluate the constants first (trig values, logs). They turn the right side into a plain number.
  • Move everything to one side: h = LHS − RHS. Count the zeros of h.
  • h' has one sign everywhere: at most one root. The signs of h at the two ends tell you whether it has one.
  • h' changes sign: split into rising and falling pieces. Each piece holds at most one zero. Test h at the turning points. Practice problem 2 does this.
  • Quick positivity tools: e^t ≥ t + 1 and ln t ≤ t − 1.
  • Use a sketch to guess, never to decide.

The shortcuts
  • Write the range of each inverse function before you solve: sin⁻¹ ∈ [−π/2, π/2], cos⁻¹ ∈ [0, π], tan⁻¹ ∈ (−π/2, π/2), cot⁻¹ ∈ (0, π).

4 · Pair of lines: the angle bisector formula

Coordinate geometryNew this time

A pair of lines through the origin, ax² + 2hxy + by² = 0, has slopes with m₁ + m₂ = −2h/b and m₁m₂ = a/b. Its two angle bisectors satisfy h(x² − y²) = (a − b)xy. If you know where that comes from, you cannot confuse it with the formula for the angle between the lines.

Worked example · the exact problem you saw

For the pair of lines ax² + 2hxy + by² = 0, if the slope of one of the angle bisectors is 3, then 3 |(a − b)/h| is equal to

Your answer was 6. Correct answer: 8.

Step 1 · where the bisector formula comes from Let the lines have inclinations α, β (slopes tan α = m₁, tan β = m₂). A bisector has inclination θ = (α + β)/2 (the other bisector is 90° away). So tan 2θ = tan(α + β) = (m₁ + m₂)/(1 − m₁m₂).
Step 2 · put in the pair's slopes m₁ + m₂ = −2h/b and m₁m₂ = a/b. So tan 2θ = (−2h/b)/(1 − a/b) = −2h/(b − a) = 2h/(a − b).
Step 3 · write tan 2θ with the bisector's slope With bisector slope m = tan θ: 2m/(1 − m²) = 2h/(a − b), so (a − b)m = h(1 − m²). Writing m = y/x gives h(x² − y²) = (a − b)xy. The other bisector has slope −1/m and satisfies the same equation.
Step 4 · use m = 3 (a − b)·3 = h(1 − 9) = −8h, so (a − b)/h = −8/3.
Step 5 · check with real numbers, then finish Take a = −4, h = 3, b = 4: then (a − b)/h = −8/3. The slopes solve 4m² + 6m − 4 = 0, so m = 1/2 and m = −2. The shortcuts
  • Bisectors: h(x² − y²) = (a − b)xy. In slope form, h(1 − m²) = (a − b)m. It holds for both bisectors, so m = 3 and m = −1/3 give the same (a − b)/h.
  • Why: tan 2θ = 2h/(a − b), where θ is the inclination of a bisector.
  • Angle between the lines is a different formula: tan φ = 2√(h² − ab) / |a + b|.
  • Slopes of the pair satisfy bm² + 2hm + a = 0: sum −2h/b, product a/b.
  • Quick tests: a + b = 0 means perpendicular lines. h² = ab means coincident lines. a = b means the bisectors are y = ±x.

The shortcuts
  • Functional equation with a polynomial f: compare degrees, use x = 0 (and x = 1, −1) for constants, match coefficients, then check one value.
  • Divisibility by a quadratic: put the roots in. On x² = x + 1 powers reduce to Fx + F'. For x² + x + 1, use ω³ = 1 and 1 + ω + ω² = 0.
  • Multi-correct: write T or F beside every option before you choose. Never stop after the first true one.
  • Options often share one result. Find the result, then check all four against it. For "greater than" options, the strongest bound makes every weaker one true.
  • Count first: if the stem says "select all", expect 2 or 3 true options, and keep looking until you have tested all four.

1Single-correctTrig root countingL4

The number of real values of x satisfying sec(π√(x² − 3x)) · sec(π√(25 − x²)) = −1 is:

Pick one option.

Answer: C · 2
  1. Both secants have size at least 1, so the product is −1 only if each is ±1 with opposite signs. Then A = √(x² − 3x) and B = √(25 − x²) are whole numbers with A + B odd (cos kπ = (−1)^k).
  2. B whole, 0 ≤ B ≤ 5, so x² ∈ {25, 24, 21, 16, 9, 0}. Candidates: x = ±5, ±√24, ±√21, ±4, ±3, 0.
  3. x = ±√24, ±√21: A² = x² − 3x = 24 ∓ 3√24 (or 21 ∓ 3√21) is irrational, so A is not whole. Out.
  4. x = 5: A² = 10. x = −5: A² = 40. x = −4: A² = 28. x = −3: A² = 18. None is a square. Out.
  5. x = 4: A² = 16 − 12 = 4, A = 2, B = 3, A + B = 5 odd. sec 2π · sec 3π = (1)(−1) = −1. Works.
  6. x = 0: A = 0, B = 5, A + B = 5 odd. sec 0 · sec 5π = (1)(−1) = −1. Works.
  7. x = 3: A² = 0, A = 0, B = 4, A + B = 4 even. sec 0 · sec 4π = +1. Fails. So 2 solutions: x = 4 and x = 0.
  • A (0): decided the product cannot reach −1 (the same slip as in CTA20 Q10)
  • B (1): dropped x = 0 because the first radicand is 0; but 0 is a whole number and sec 0 = 1
  • D (3): counted x = 3 without testing the parity of A + B

2Single-correctRoots by derivativeL4

The number of real roots of the equation e^x = (8 sin75° cos75°) · x² is:

Pick one option.

Answer: C · 3
  1. 8 sin75° cos75° = 4 sin150° = 4 × 1/2 = 2. The equation is e^x = 2x². Let g(x) = e^x − 2x²; count its zeros.
  2. g'(x) = e^x − 4x and g''(x) = e^x − 4. So g' has its minimum at x = ln 4, where g'(ln 4) = 4 − 4 ln 4 = 4(1 − ln 4) < 0 (since ln 4 > 1).
  3. For x ≤ 0, g'(x) > 0; and g'(x) → ∞ as x → ∞. So g' has exactly two zeros p < ln 4 < q, and g rises on (−∞, p), falls on (p, q), rises on (q, ∞).
  4. g(0) = 1 > 0 and g is rising up to p > 0, so g(p) > 1 > 0. Also g'(2) = e² − 8 < 0, so 2 ∈ (p, q), and g(q) < g(2) = e² − 8 < 0.
  5. Signs: g(−∞) = −∞, g(p) > 0, g(q) < 0, g(∞) = +∞. One zero in each of the three pieces. Total 3 (at about −0.54, 1.49, 2.62).
  • A (1): treated g as rising because e^x eventually beats 2x²
  • B (2): found the two positive crossings and forgot the negative one (g(0) = 1 > 0 while g → −∞ on the left)
  • D (4): doubled the positive roots as if x² made the equation symmetric; e^x is not even

3Single-correctInverse trig matchL4

Match List-I with List-II.
P) (12/π) · [ tan⁻¹(1/3) + tan⁻¹(1/5) + tan⁻¹(1/7) + tan⁻¹(1/8) ]
Q) Number of real solutions of sin⁻¹x + sin⁻¹(2x) = π/2
R) Number of solutions of sin⁻¹(sin x) = x/2 in [0, 4π]
S) lim(x→0) (sin⁻¹x − tan⁻¹x) / x³
List-II p) 0 q) 1/6 r) 1/2 s) 1 t) 2 u) 3

Pick one option.

Answer: A · P→u; Q→s; R→t; S→r
  1. P: tan⁻¹(1/3) + tan⁻¹(1/5) = tan⁻¹((8/15)/(14/15)) = tan⁻¹(4/7). tan⁻¹(1/7) + tan⁻¹(1/8) = tan⁻¹((15/56)/(55/56)) = tan⁻¹(3/11). Then tan⁻¹(4/7) + tan⁻¹(3/11) = tan⁻¹((65/77)/(65/77)) = tan⁻¹1 = π/4. Every product ab is below 1, so no π is added. (12/π)(π/4) = 3: P→u.
  2. Q: sin⁻¹(2x) = π/2 − sin⁻¹x = cos⁻¹x. The left side is in [−π/2, π/2], so cos⁻¹x ≤ π/2 and x ≥ 0. Take sine: 2x = √(1 − x²), so 5x² = 1, x = 1/√5 ≈ 0.447 (and 2x ≤ 1 holds). The root −1/√5 comes from squaring and fails x ≥ 0: it gives −0.463 − 1.107 = −π/2. One solution: Q→s.
  3. R: sin⁻¹(sin x) is x on [0, π/2], π − x on [π/2, 3π/2], and never exceeds π/2. So x/2 ≤ π/2, i.e. x ≤ π. On [0, π/2]: x = x/2 gives x = 0. On [π/2, π]: π − x = x/2 gives x = 2π/3, which is in range. Beyond π the line is above the curve. Two solutions: R→t.
  4. S: sin⁻¹x = x + x³/6 + … and tan⁻¹x = x − x³/3 + … (integrate (1 − x²)^(−1/2) = 1 + x²/2 + … and 1/(1 + x²) = 1 − x² + …). The difference is x³/6 + x³/3 = x³/2, so the limit is 1/2: S→r.
  5. P→u, Q→s, R→t, S→r is option A.
  • B: Q→t, kept the extra root −1/√5 created by squaring
  • C: R→s, found only x = 0 and missed the branch π − x (root 2π/3); S→q, took tan⁻¹x ≈ x to the cubic order and got 1/6
  • D: S→p, said both functions are about x so the difference is 0, ignoring the cubic terms

4Single-correctPair of linesL4

One line of the pair ax² + 2hxy + by² = 0 is y = 3x, and one of the angle bisectors of the pair has slope 2. Then a/b equals:

Pick one option.

Answer: D · 13/3
  1. Let the lines have inclinations α, β with tan α = 3 and tan β = m₂. A bisector has inclination θ = (α + β)/2 (or 90° more), so tan 2θ = tan(α + β) either way.
  2. With tan θ = 2: tan 2θ = 2·2/(1 − 4) = −4/3.
  3. tan(α + β) = (3 + m₂)/(1 − 3m₂) = −4/3. So 3(3 + m₂) = −4(1 − 3m₂), i.e. 9 + 3m₂ = −4 + 12m₂, so m₂ = 13/9.
  4. The slopes satisfy bm² + 2hm + a = 0, so their product is a/b. Hence a/b = 3 × 13/9 = 13/3.
  5. Check: atan 3 = 71.57° and atan(13/9) = 55.30°. The average is 63.43° = atan 2. ✓ (The other bisector, slope −1/2, gives the same tan 2θ.)
  • A: used tan 2θ = 2m/(1 + m²) = 4/5 (sign slip in the double-angle formula), so m₂ = −11/17 and a/b = −33/17
  • B: used tan(α + β) = (m₁ + m₂)/(1 + m₁m₂) (wrong sign in the denominator), so m₂ = −13/15 and a/b = −13/5
  • C: took the bisector slope as the average of the slopes: (3 + m₂)/2 = 2, so m₂ = 1 and a/b = 3

5Multi-correctFunctional equation · multi-correctL4

A function f is defined for all real x ≠ 0, 1 and satisfies f(x) + f(1/(1 − x)) = x. Select all correct statements.

Select every correct option. It counts only if your set matches exactly.

Answer: A, C
  1. Start at x = 2: 1/(1 − 2) = −1; then 1/(1 − (−1)) = 1/2; then 1/(1 − 1/2) = 2. The cycle closes after three steps, so only 2, −1, 1/2 are linked. All three are valid inputs.
  2. The rule at each of the three: f(2) + f(−1) = 2, f(−1) + f(1/2) = −1, f(1/2) + f(2) = 1/2.
  3. Add them: 2[f(2) + f(−1) + f(1/2)] = 2 − 1 + 1/2 = 3/2, so the sum is 3/4. D says 3/2: false.
  4. f(2) = 3/4 − (f(−1) + f(1/2)) = 3/4 − (−1) = 7/4. A is true.
  5. f(−1) = 3/4 − (f(1/2) + f(2)) = 3/4 − 1/2 = 1/4. B says −1/4: false.
  6. f(1/2) = 3/4 − (f(2) + f(−1)) = 3/4 − 2 = −5/4. C is true. Check: 7/4 + 1/4 = 2, 1/4 − 5/4 = −1, −5/4 + 7/4 = 1/2. ✓
  • B: sign slip, used f(−1) = f(2) − 2 instead of 2 − f(2)
  • D: added the three right sides (3/2) and forgot to halve

6Multi-correctMulti-correct · divisibilityL4

Let P(x) = x¹⁰⁰ + a x⁵⁰ + b with real a, b. Select all correct statements.

Select every correct option. It counts only if your set matches exactly.

Answer: A, B, D
  1. A: the roots of x² + x + 1 are ω, ω² with ω³ = 1. 100 = 3·33 + 1 and 50 = 3·16 + 2, so ω¹⁰⁰ = ω, ω⁵⁰ = ω², and (ω²)¹⁰⁰ = ω², (ω²)⁵⁰ = ω. So P(ω) = ω + aω² + b = 0 and P(ω²) = ω² + aω + b = 0.
  2. Subtract: (ω − ω²)(1 − a) = 0, so a = 1. Then b = −ω − ω² = 1. Conversely a = b = 1 makes both zero. A is true (an if and only if).
  3. B: P(x) = Q(x²) with Q(y) = y⁵⁰ + y²⁵ + 1. At y = ω: ω⁵⁰ = ω² and ω²⁵ = ω, so Q(ω) = ω² + ω + 1 = 0. So y² + y + 1 divides Q(y), and x⁴ + x² + 1 divides P(x). B is true.
  4. C: x⁴ + x² + 1 = (x² + x + 1)(x² − x + 1). So x² − x + 1 divides P(x) as well. C says it does not: false.
  5. D: modulo x² + 1, x² ≡ −1. So x¹⁰⁰ = (x²)⁵⁰ = 1 and x⁵⁰ = (x²)²⁵ = −1. The remainder is 1 − 1 + 1 = 1. D is true.
  • C: assumed only x² + x + 1 matters; missed that x⁴ + x² + 1 also contains the factor x² − x + 1
