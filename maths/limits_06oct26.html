1 · Series and standard limits: expand, match, test every case

LimitsCame back

When a limit gives 0/0, you have two tools. For products and quotients, replace each factor by its first term. For sums and differences, expand to the power the bottom needs, because the first terms usually cancel. Mixing these up, or stopping one term early, is where WTA19 cost you marks in Q8, Q9, Q18 and Q7.

The shortcuts
  • Match the order. If the bottom is xⁿ, the top must be known to xⁿ. For a finite limit every lower power must have coefficient 0, and the xⁿ coefficient is the limit.
  • Products and quotients only: replace by first terms. sin u ≈ u, tan u ≈ u, ln(1+u) ≈ u, e^u − 1 ≈ u, 1 − cos u ≈ u²/2, a^u − 1 ≈ u ln a. Watch the u: for 1 − cos 2x it is 2x, so the answer is 2x².
  • Sums and differences: never use first terms. Expand fully. Example: e^(x²) − cos x = (3/2)x² + (11/24)x⁴ + …, and the x² term may cancel against something else.
  • Rationalise a root difference: √(x²+c) − √c = x² / (√(x²+c) + √c).
  • Several options or cases (multi-correct): treat each option or each value of k as its own limit and test it. Do not stop at the first one that works.

The shortcuts
  • Check it is really 1^∞: the base must go to 1 and the exponent to ∞. If the base has a free constant, choose it first so the base goes to 1 (your Q8 has a constant that must be fixed this way).
  • Then: lim f^g = e^(lim (f − 1)·g). Compute (f − 1) with series (it is a difference, so use full expansions): cos x − 1 ≈ −x²/2, tan x − sin x ≈ x³/2.
  • Limits at ∞: put t = 1/x so that t → 0. Then x sin(1/x) = sin t / t = 1 − t²/6 + ….
  • A limit as n → ∞ of (…)ⁿ works the same way: (1 + A/n)ⁿ → e^A.

The shortcuts
  • Factor, then split into ratios: ln[(n−1)(n+1) / (n(n+2))] = ln[(n−1)/n] + ln[(n+1)/(n+2)]. Each ratio telescopes alone.
  • Sum of logs = log of a product. Telescoping a product: the top of each factor cancels the bottom of a later one. Write the first three and last three factors to see what survives.
  • Partial fractions: 1/(k(k+2)) = ½(1/k − 1/(k+2)). Two terms survive at each end, not one.
  • Terms going to 0 does not mean the sum converges: Σ ln(1 + 1/k) = ln(n+1) → ∞.
  • Outer layers: e^u − 1 ≈ u for small u. Then the rate (a power of m) decides α and L.
Your WTA19 Q14, solved with the same idea (the portal does not show the sum's limits; I took ‹r = 0› to ‹n›, which gives the key 1): the term ‹(t + t³)/(1 − t²)› with ‹t = tan θ› and ‹θ = x/2^(r+1)› equals ‹tan θ · sec 2θ = tan 2θ − tan θ›, which is ‹tan(x/2^r) − tan(x/2^(r+1))›. The sum telescopes to ‹tan x − tan(x/2^(n+1)) → tan x›, so ‹λ = lim tan x / x = 1›.

The shortcuts
  • For each floor, ask two things: is the limit an integer, and if so, does the value approach it from above or from below? Test both sides x → 0⁺ and x → 0⁻ separately when the function is not even.
  • Series tell you the side. sin x / x = 1 − x²/6 is below 1. tan x / x = 1 + x²/3 is above 1. (eˣ − 1)/x = 1 + x/2 is above 1 for x > 0 and below for x < 0.
  • Principal values: tan⁻¹ takes values in (−π/2, π/2). tan⁻¹(1/x) → +π/2 as x → 0⁺ and −π/2 as x → 0⁻. The limit at 0 does not exist.
  • Bounded × null → 0: x · tan⁻¹(1/x) → 0.

lim (n→∞) Π (k³ − 1)/(k³ + 1), with the product taken for k = 2 to n, equals:

Pick one option.

Answer: C · 2/3
  1. k³ − 1 = (k−1)(k² + k + 1) and k³ + 1 = (k+1)(k² − k + 1).
  2. Insight: k² + k + 1 = (k+1)² − (k+1) + 1. So with g(k) = k² − k + 1, we have k² + k + 1 = g(k+1).
  3. Each term is [(k−1)/(k+1)] · [g(k+1)/g(k)].
  4. Π (k−1)/(k+1) for k = 2 to n: (1/3)(2/4)(3/5)⋯((n−1)/(n+1)) = (1·2)/(n(n+1)) = 2/(n(n+1)).
  5. Π g(k+1)/g(k) = g(n+1)/g(2) = (n² + n + 1)/3.
  6. The product is 2(n² + n + 1) / (3n(n+1)) → 2/3.
  • A: kept only the (k−1)/(k+1) product, which → 0
  • B: wrote Π (k−1)/(k+1) = 1/(n(n+1)), missing the 2 from the k = 2 start
  • D: said "each factor → 1, so the product → 1"

11Single-correctFloor / one-sidedL4

F(x) = ⌊(e^x − 1)/x⌋ + ⌊sin x / x⌋ + ⌊tan x / x⌋ + ⌊x / sin⁻¹x⌋. Let L⁺ and L⁻ be the limits of F(x) as x → 0⁺ and x → 0⁻. Then 10L⁺ + L⁻ equals:

Pick one option.

Answer: B · 21
  1. A floor is decided by which side of an integer the value is on. Check each term for x → 0⁺ and for x → 0⁻.
  2. (e^x − 1)/x = 1 + x/2 + …: above 1 for x > 0 (floor 1), below 1 for x < 0 (floor 0).
  3. sin x / x = 1 − x²/6: below 1 on both sides. Floor 0.
  4. tan x / x = 1 + x²/3: above 1 on both sides. Floor 1.
  5. sin⁻¹x = x + x³/6, so x / sin⁻¹x = 1 − x²/6: below 1 on both sides. Floor 0.
  6. L⁺ = 1 + 0 + 1 + 0 = 2 and L⁻ = 0 + 0 + 1 + 0 = 1. So 10L⁺ + L⁻ = 21.
  • A: swapped the two sides: 10 · 1 + 2
  • C: took (e^x − 1)/x as above 1 on both sides, so L⁻ = 2
  • D: took sin x / x as above 1, so L⁺ = 3 and L⁻ = 2

12Multi-correctFloor / one-sidedL4

All inverse trigonometric functions take principal values. Select all correct statements.

Select every correct option. It counts only if your set matches exactly.

Answer: A, C, D
  1. A: as x → 0⁺, 1/x → +∞, so tan⁻¹(1/x) → π/2. True.
  2. B: as x → 0⁻, 1/x → −∞, so tan⁻¹(1/x) → −π/2, not +π/2. False. (The two sides differ, so the limit at 0 does not exist.)
  3. C: |tan⁻¹(1/x)| < π/2 is bounded and x → 0. Bounded × null → 0. True.
  4. D, right side: (2/π) tan⁻¹(1/x) is always below 1 and approaches 1. From below, the floor is 0.
  5. D, left side: it is always above −1 and approaches −1. From above, the floor is −1. So D is true.
  • B: treated tan⁻¹ of a large number as π/2 whatever its sign
