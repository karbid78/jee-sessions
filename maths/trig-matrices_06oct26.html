Worked example · the exact problem you saw

In [0, π], the equation sec 2x − sec x = 2 has three roots x₁ < x₂ < x₃. If π/(x₁+x₂+x₃) = m/n in lowest terms, find n − m.

You skipped this one. Correct answer: 4 (the roots are π/5, 3π/5 and π).

Step 1 · turn secants into cosines Let c = cos x. Then cos 2x = 2c² − 1, and the equation is 1/(2c² − 1) − 1/c = 2Neither c nor 2c² − 1 may be 0. Multiply through by c(2c² − 1): c − (2c² − 1) = 2c(2c² − 1)
Step 2 · make it a cubic Expand: c − 2c² + 1 = 4c³ − 2c, so 4c³ + 2c² − 3c − 1 = 0Try c = −1: −4 + 2 + 3 − 1 = 0. So (c + 1) is a factor: (c + 1)(4c² − 2c − 1) = 0Hence c = −1 or c = (1 ± √5)/4.
Step 3 · turn each c into one angle (1+√5)/4 = cos 36° = cos(π/5) and (1−√5)/4 = cos 108° = cos(3π/5), and c = −1 gives x = π.On [0, π] the cosine is one-to-one, so every value of c in [−1, 1] gives exactly one x. Three values of c mean three roots.
Step 4 · check the denominators We needed cos x ≠ 0 and cos 2x ≠ 0. For x = π/5, 3π/5, π the values of cos 2x are cos 72°, cos 216°, cos 2π, none zero, and cos x is never zero. No root is spoiled.
Step 5 · finish x₁ + x₂ + x₃ = π/5 + 3π/5 + π = 9π/5. Then π/(9π/5) = 5/9, so m = 5, n = 9.n − m = 4
Answer: 4
The trap: leaving it because it is a secant question. Writing c = cos x turns it into a cubic with a root you can guess (−1). Then the one-to-one check on [0, π] turns three values of c into three roots.

The shortcuts
  • Two checks, always: (1) which values can the expression take, (2) how many angles give each value. On [0, π] cos is one-to-one: 1 angle per value. On a full turn, sin or cos gives 2 angles per interior value and 1 at ±1.
  • Never divide by something that can be 0. Move everything to one side and factor. Cancelling tan x from tan 2x = 3 tan x loses the roots 0 and π.
  • sin A = cos B: write cos B = sin(π/2 − B). Then sin X = sin Y has two families: X = Y + 2nπ and X = π − Y + 2nπ. Use both.
  • cosθ ± sinθ lies in [−√2, √2], not [−1, 1]. List every allowed value and test the largest against 1.414 (for example 5/4 is allowed).
  • A fraction with a common factor: cancel it, but the value at the hole can never be taken. It becomes an excluded value of the whole expression.
  • Quadratic in cos x: check both roots against [−1, 1] before counting.
Your CTA19 Q11, set up (the portal did not store the exact question, so I stop where the text stops): ‹(x³ − 6x² + 11x − 6)/(x³ + x² − 10x + 8) = (x−1)(x−2)(x−3) / ((x−1)(x−2)(x+4)) = (x−3)/(x+4)›, with holes at ‹x = 1› and ‹x = 2›. Worked example · the exact problem you saw

Let α = ∏ (1 − 2cos(3ᵏπ/11)) for k = 0, 1, 2, 3, 4. Find 5 − α².

Your answer was 2. Correct answer: 4 (so α = 1).

Step 1 · look for the tell The angles are π/11, 3π/11, 9π/11, 27π/11, 81π/11. Each is 3 times the one before. That points to an identity with 3θ/2, which is a triple-angle formula in disguise.
Step 2 · build the identity Start from cos 3t = 4cos³t − 3cos t = cos t (4cos²t − 3) = cos t (2cos 2t − 1). Put t = θ/2: cos(3θ/2) = cos(θ/2)(2cos θ − 1). So 1 − 2cos θ = −cos(3θ/2) / cos(θ/2)Quick check at θ = 0: left side −1, right side −1/1.
Step 3 · write the product and let it telescope Factor k has θ = 3ᵏπ/11, so it equals −cos(3ᵏ⁺¹π/22) / cos(3ᵏπ/22). Multiply the five factors, k = 0 to 4. The top of each factor cancels the bottom of the next: α = (−1)⁵ · cos(3⁵π/22) / cos(π/22) = −cos(243π/22) / cos(π/22)
Step 4 · reduce the big angle 11π = 242π/22, so 243π/22 = 11π + π/22. Adding an odd multiple of π flips the sign: cos(11π + u) = −cos u. So cos(243π/22) = −cos(π/22). α = −(−cos(π/22)) / cos(π/22) = 1
Step 5 · finish 5 − α² = 5 − 1 = 4.
Answer: 4
I can't see your working, so I can't say where your 2 came from (it needs α² = 3). The usual slip here is a sign: five factors give (−1)⁵, and then the big angle flips the sign once more. Count both flips before you write the answer.

Identities to recognise on sight
  • Cot difference: 1/(sin a · sin(a+d)) = (cot a − cot(a+d)) / sin d. With a step of 2 or a range symmetric about 90°, pair terms using cot(180° − x) = −cot x.
  • Angles that triple: 1 − 2cosθ = −cos(3θ/2)/cos(θ/2) and 1 + 2cosθ = sin(3θ/2)/sin(θ/2). The product over θ, 3θ, 9θ, … telescopes.
  • Angles that double: cot t − cot 2t = cosec 2t and tan t = cot t − 2cot 2t. Sums with 2ᵏ or 1/2ᵏ in front telescope.
  • Tangent of a difference: tan(k+1)° − tan k° = tan 1° (1 + tan k° tan(k+1)°). Sums of tan k° tan(k+1)° telescope.
  • Ratio of sines: if sin(α+β)/sin(α−β) = p/q then tanα/tanβ = (p+q)/(p−q).
  • Last step: reduce a big angle by whole multiples of π and track the sign. An odd multiple flips it.

Worked example · the exact problem you saw

Δ = a+b+2cabcb+c+2abcac+a+2b = k(αa + βb + γc)³ for integers k, α, β, γ. Find (2α + β + γ)ᵏ.

Your answer was 1024. Correct answer: 16 (k = 2, α = β = γ = 1).

Step 1 · look at the row sums Row 1: (a+b+2c) + a + b = 2(a+b+c). Row 2: c + (b+c+2a) + b = 2(a+b+c). Row 3: c + a + (c+a+2b) = 2(a+b+c). Every row sums to the same thing.
Step 2 · add all columns into column 1 C₁ → C₁ + C₂ + C₃. Now column 1 is 2(a+b+c) in every row. Factor it out: Δ = 2(a+b+c) × det 1ab1b+c+2ab1ac+a+2b
Step 3 · clear column 1 R₂ → R₂ − R₁ gives the row (0, a+b+c, 0). R₃ → R₃ − R₁ gives (0, 0, a+b+c).
Step 4 · the matrix is now triangular The determinant is the product of the diagonal: 1 · (a+b+c) · (a+b+c). So Δ = 2(a+b+c)³
Step 5 · read off and finish k = 2, α = β = γ = 1. Then (2α + β + γ)ᵏ = (2+1+1)² = 4² = 16.
Answer: 16
The trap: expanding the determinant term by term. That is six products of three terms, easy to slip on, and the cube is hard to see in the result. Equal row sums or column sums mean: add everything into one line, factor, then subtract. Also read the question for what the exponent is: it is k = 2, not 3.

The shortcuts
  • Equal row or column sums: add all rows (or columns) into one, factor out the common sum, then subtract to clear zeros.
  • For a 3×3 matrix: det(kA) = k³ det A, adj(kA) = k² adj A, det(adj A) = (det A)².
  • QR = RP with R invertible (your CTA19 Q6 idea): multiply by R⁻¹ to get Q = R P R⁻¹. Then Q − λI = R(P − λI)R⁻¹, so det(Q − λI) = det(P − λI). You only need det(XY) = det X · det Y. No eigenvalue theory.
  • A matrix equation like A² − 2A + I = 0: read it two ways, A(2I − A) = I (gives the inverse) and (A − I)² = 0. But (A − I)² = 0 does not force A = I. Matrices are not numbers.
  • Linear system with parameters: find the coefficient determinant. If it is not 0, there is one solution. If it is 0, row-reduce and check consistency: that decides between none and infinitely many.
  • Multi-correct habit: write T or F beside every option with a one-line reason before you tick anything.

The number of solutions of sin(2π cosθ) = cos(2π sinθ) in θ ∈ [0, 2π] is:

Pick one option.

Answer: C · 12
  1. Write cos(2π sinθ) = sin(π/2 − 2π sinθ). Then sin X = sin Y has two families: X = Y + 2nπ and X = π − Y + 2nπ.
  2. Family 1: 2π cosθ = π/2 − 2π sinθ + 2nπ, so cosθ + sinθ = 1/4 + n.
  3. Family 2: 2π cosθ = π/2 + 2π sinθ + 2nπ, so cosθ − sinθ = 1/4 + n.
  4. Both left sides lie in [−√2, √2] ≈ [−1.414, 1.414]. The values 1/4 + n allowed are −3/4, 1/4, 5/4. The next ones, −7/4 and 9/4, are outside. So 3 values per family.
  5. Each value with |k| < √2 gives 2 angles in one turn (cosθ + sinθ = √2 sin(θ + π/4) and cosθ − sinθ = √2 cos(θ + π/4)). So 3 × 2 = 6 angles per family.
  6. Overlap: a θ in both families needs cosθ = (k₁+k₂)/2, sinθ = (k₁−k₂)/2, so k₁² + k₂² = 2. No pair from {−3/4, 1/4, 5/4} does that, so no angle is counted twice. The ends θ = 0, 2π are not roots (the left side is 0, the right side is 1).
  7. Total: 6 + 6 = 12.
  • A: used only one family, so 6 instead of 12
  • B: used the bound 1 instead of √2, which drops k = 5/4 (2 values × 2 angles × 2 families)
  • D: used the bound 2, which lets in −7/4, but 7/4 > √2

Let S be the sum of all solutions of tan 2x = 3 tan x in [0, π]. Then S/π equals:

Pick one option.

Answer: B · 2
  1. Domain first: tan x is undefined at π/2, and tan 2x is undefined at π/4 and 3π/4. None of these can be a solution.
  2. Let t = tan x. Then tan 2x = 2t/(1 − t²), and the equation is 2t/(1 − t²) = 3t.
  3. Do not divide by t. Clear the denominator: 2t = 3t(1 − t²), so 3t³ − t = 0, so t(3t² − 1) = 0.
  4. t = 0 gives x = 0 and x = π. Both are in the interval, and both satisfy the original (0 = 0).
  5. 3t² = 1 gives t = ±1/√3, so x = π/6 and x = 5π/6.
  6. None of the four is an excluded point. S = 0 + π/6 + 5π/6 + π = 2π, so S/π = 2.

  • D: also counted x = π/4 and 3π/4, where tan 2x is undefined

Consider the system x + y + z = 6, x + 2y + 3z = 14, x + 2y + λz = μ. Select all correct statements.

Select every correct option. It counts only if your set matches exactly.

Answer: A, B, C
  1. Coefficient determinant: R₂ − R₁ = (0, 1, 2) and R₃ − R₁ = (0, 1, λ−1), so the determinant is 1·(λ−1) − 2·1 = λ − 3.
  2. λ ≠ 3: the determinant is not 0, so there is exactly one solution, for every μ. A is true.
  3. λ = 3: equations 2 and 3 have the same left side x + 2y + 3z. Subtracting them gives 0 = μ − 14.
  4. μ = 14: the two equations are identical, leaving two independent equations in three unknowns. Taking z = t: y = 8 − 2t, x = t − 2. Infinitely many solutions. B is true.
  5. μ = 15: subtracting gives 0 = 1, a contradiction. No solution. C is true.
  6. So with λ = 3, the answer depends on μ: μ = 14 gives infinitely many, any other μ gives none. D is false.
  • D: read “determinant is 0” as “infinitely many solutions”. Determinant 0 means infinitely many or none, and consistency decides which

12Multi-correctMatricesL4

P = 140025007. Q and R are 3×3 real matrices with R invertible and QR = RP. Select all correct statements.

Select every correct option. It counts only if your set matches exactly.

Answer: A, B, D
  1. Multiply QR = RP on the right by R⁻¹: Q = R P R⁻¹.
  2. det Q = det R · det P · det R⁻¹ = det P. P is upper triangular, so det P = 1 · 2 · 7 = 14. A is true.
  3. Q − 6I = R P R⁻¹ − 6 R R⁻¹ = R(P − 6I)R⁻¹. So det(Q − 6I) = det(P − 6I).
  4. P − 6I is upper triangular with diagonal −5, −4, 1, so its determinant is (−5)(−4)(1) = 20. B is true.
  5. D: Q²R = Q(QR) = Q(RP) = (QR)P = (RP)P = RP². D is true.
  6. C: take R = diag(1, 1, 2). Then Q = R P R⁻¹ has second-row, third-column entry 5 · (1/2) = 5/2, which is not 5. So Q ≠ P. C is false.
  • C: saw that the determinants agree and concluded the matrices must be equal. The same determinant does not mean the same matrix
