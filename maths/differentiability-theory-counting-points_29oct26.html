Worked example · the exact problem you saw

A function is defined by f(x) = sin⁻¹(2x/(1+x²)) for x ≤ 0, f(x) = [3x] for 0 < x < k, and f(x) = (x − α)² + β for x ≥ k. It is non-derivable at exactly 7 points. Find α + β + k. ([·] is the greatest integer function.) My saved copy does not show the condition on k. The key 9 needs k = 2, so I take k to be a positive integer.

Your answer was 4. Correct answer: 9. Here's why.

Step 1 · the left piece changes formula at x = −1 Put x = tan t. For −1 ≤ x ≤ 0, 2x/(1+x²) = sin 2t with 2t ∈ [−π/2, 0], so f = 2tan⁻¹x, slope 2/(1+x²). For x < −1, 2t ∈ (−π, −π/2) and f = −π − 2tan⁻¹x, slope −2/(1+x²). At x = −1 the value is −π/2 on both sides, the slopes are −1 (left) and +1 (right). A kink: 1 point.
Step 2 · the kink at x = 0 At x = 0, f(0) = sin⁻¹0 = 0. The left slope is 2/(1+0) = 2. On the right, [3x] = 0 for 0 < x < 1/3, so the function is continuous (0 = 0) with slope 0. 2 ≠ 0: another kink. 2 points so far.
Step 3 · the jumps inside (0, k) [3x] is flat between jumps and goes up by 1 at every x = m/3. A jump is a break of continuity, so it is a non-derivable point. The candidates are 1/3, 2/3, 1, 4/3, 5/3, 2, … as long as they are below k.
Step 4 · the join at x = k Just left of k the function is flat at some level c. Right of k the parabola has slope 2(k − α). For x = k to be derivable you need β = c (continuity) and 2(k − α) = 0, so α = k. If either failed, α and β would not be pinned down and the question could not ask for α + β + k. A flat vertex at the join also hides a jump that sits exactly at x = k.
Step 5 · count to 7, then fix k Two points come from the kinks (−1 and 0). The other 5 must be jumps: 1/3, 2/3, 1, 4/3, 5/3. The next jump, x = 2, must not be inside (0, k), so 5/3 < k ≤ 2. For an integer k that is k = 2. (Any k in that range gives 7 points and the sum 2k + 5, so the integer condition is what makes the answer 9.)
Step 6 · read off β and α For x just below 2, [3x] = 5, so β = 5. Then α = k = 2. The jump at x = 2 is hidden by the join, so it is not extra. α + β + k = 2 + 5 + 2 = 9.
Answer: 9
The trap: stopping the jump list early, and forgetting that the join at x = k decides α and β. With only the jumps at 1/3 and 2/3 (k = 1) you get the sum 4 and a function with 4 points, not 7. Also easy to miss: the kink at x = −1, because sin⁻¹(2x/(1+x²)) equals 2tan⁻¹x only for |x| ≤ 1.

The shortcuts
  • Write the whole list before you count. Kinks of every piece, jumps of every [·] and {·}, and every join. Then test each point once.
  • Jumps cancel only when their signs are opposite. [kx] jumps +1 and {kx} jumps −1 at multiples of 1/k, so [5x] + {3x} cancels at shared points. [3x] − {4x} does not (+1 and +1 add to +2).
  • Inverse trig changes formula. sin⁻¹(2x/(1+x²)) = 2tan⁻¹x only for |x| ≤ 1. Outside it is ±π − 2tan⁻¹x, so there is a kink at x = ±1.
  • A smooth join needs two things: equal values and equal slopes. A flat piece meeting a parabola needs the vertex at the join. That also hides a jump sitting at the join.
  • A zero factor helps differently for continuity and derivability. [x]·sin πx is continuous at integers (the factor is 0) but not derivable. [x]·sin²πx is derivable (the factor is 0 to second order).

ContinuitySlippedSun · CTA21

Worked example · the exact problem you saw

Select the correct statements. (A) If f′(x) is continuous at x = a, then f is differentiable at a. (B) f′(x) can be discontinuous at a point where f is differentiable. (C) f is smooth at a if and only if f′(a) exists. (D) If f is differentiable at a, then lim f′(x) = f′(a) as x → a.

Your answer was A, C, D. Correct answer: A, B. I rebuilt the four statements from the saved topic lines, so check the wording against your paper. Here's why.

Step 1 · what the words mean Differentiable at a means f′(a) exists (the difference quotient has a limit). f′ continuous at a means lim f′(x) = f′(a). Smooth here means f′ is continuous at a. Differentiable is the weaker condition.
Step 2 · statement A To say f′ is continuous at a, the value f′(a) must exist. So f is differentiable at a. A is true (you had this).
Step 3 · one test function settles B, C and D Take f(x) = x² sin(1/x) with f(0) = 0. Then f′(0) = lim h² sin(1/h)/h = lim h sin(1/h) = 0 (a bounded factor times something going to 0). So f is differentiable at 0.
Step 4 · f′ near 0 For x ≠ 0: f′(x) = 2x sin(1/x) − cos(1/x). The first term goes to 0, but cos(1/x) keeps swinging between −1 and 1. So lim f′(x) does not exist, and f′ is discontinuous at 0 although f′(0) = 0 exists. B is true. D is false.
Step 5 · statement C Smooth needs f′ continuous at a. In the example f′(0) exists, yet f′ is not continuous at 0. So existence of f′(a) is not enough. C is false.
Answer: A, B
Likely cause: "f′(a) exists" and "f′ is continuous at a" felt like one idea, so C and D looked true and B looked impossible. One test function, x² sin(1/x), settles A to D at once.

Worked example · the exact problem you saw

Let f(x) = limθ→0⁻ [cos(πx) − (x²)^(1/θ) sin(πx/2)] / [1 + (x²)^(1/θ)]. Which statement about continuity and the left-hand derivative of f at x = 1 and x = −1 is NOT true?

You skipped this one. Key: C. My saved copy does not have the wording of the four statements. So below is every fact about f at ±1, which is enough to judge any of them.

Step 1 · what (x²)^(1/θ) does Write T = (x²)^(1/θ). As θ → 0⁻, 1/θ → −∞. If |x| < 1, x² < 1 and a number below 1 to a huge negative power is huge: T → ∞. If |x| > 1: T → 0. If |x| = 1: T = 1.
Step 2 · the three formulas For |x| < 1 divide top and bottom by T: f = −sin(πx/2). For |x| > 1: f = cos πx. For |x| = 1: f = (cos πx − sin(πx/2))/2.
Step 3 · x = 1 is fine f(1) = (−1 − 1)/2 = −1. Left limit −sin(π/2) = −1, right limit cos π = −1. Continuous. Slopes: left −(π/2)cos(πx/2) = 0, right −π sin πx = 0. So f is differentiable at 1, and the left-hand derivative is 0.
Step 4 · x = −1 is not f(−1) = (cos(−π) − sin(−π/2))/2 = (−1 + 1)/2 = 0. Left limit (|x| > 1): cos(−π) = −1. Right limit (|x| < 1): −sin(−π/2) = +1. Three different numbers, so f is not continuous at −1, and the left-hand derivative there does not exist (the left limit −1 is not f(−1) = 0).
Step 5 · which statement fails True: continuous at 1, left-hand derivative at 1 equal to 0, differentiable at 1. False: continuous at −1, any left-hand derivative at −1. The key letter C must be the statement that claims something at x = −1, which is the only place f misbehaves. I can't confirm the wording of C.
x = 1: continuous and differentiable. x = −1: not continuous.
The trap: x² and x^(1/θ) are even in x, so x = 1 and x = −1 feel the same. They are not, because cos πx is even but sin(πx/2) is odd. The pieces meet at 1 but not at −1.

The shortcuts
  • Differentiable implies continuous, not the other way round. And "f′(a) exists" is not "f′ is continuous at a". x² sin(1/x) has the first without the second.
  • Continuity at a join needs three numbers: left limit, right limit and the value. Derivability needs two slopes, and only after continuity holds.
  • If f is defined by a limit, first find f in each region (|x| < 1, |x| > 1, |x| = 1). The value at the boundary is its own third case.
  • Do not copy a result from x = 1 to x = −1 unless the pieces are even functions.

3 · Log differentiation of nested powers

DifferentiationNewSat · WTA21

Log differentiation is the tool for y = u^v when both parts depend on x. Here the exponent is itself a power of a log, so the log has to be taken twice. This was new on WTA21, where you skipped Q4.

New pattern. You did not attempt WTA21 Q4, so there is no wrong answer to compare. It looks like unfamiliar territory, not a slip. Log differentiation of nested powers is mechanical once you name the pieces.

Worked example · the exact problem you saw

Let y = x^((ln x)^(ln ln x)) for x > 1. Find dy/dx.

You skipped this one (not visited). Key: B and D. My saved copy keeps the key but not the option wording. B and D are the two equal forms of the answer: one written with y, one with y = x^u put back in.

Step 1 · take the first log Let u = (ln x)^(ln ln x). Then y = x^u and ln y = u ln x. Both u and ln x depend on x, so you need the product rule.
Step 2 · the exponent needs its own log Put L = ln x (L > 0 for x > 1). Then u = L^(ln L), so ln u = (ln L)². That is a second log, and it is what makes u differentiable.
Step 3 · differentiate u u′/u = 2 ln L · (1/L) · (1/x): the 2 ln L is from the square, 1/L from ln L, and 1/x from L = ln x. So u′ = 2u ln L / (x L).
Step 4 · differentiate ln y (ln y)′ = u′ ln x + u · (1/x). Since ln x = L: u′ ln x = 2u ln L / x. So (ln y)′ = (u/x)(2 ln L + 1).
Step 5 · multiply back by y dy/dx = (y/x) · (ln x)^(ln ln x) · (1 + 2 ln ln x). Replace y = x^u: dy/dx = x^(u−1) · u · (1 + 2 ln ln x) with u = (ln x)^(ln ln x). These are the two forms the key marks, B and D.
Answer: B and D
The trap: the exponent is itself a power, so one log is not enough. Take a second log of the exponent before you differentiate it. The second trap is dropping the u/x term, which comes from the product u · ln x.

The shortcuts
  • Base and exponent both depend on x? Take ln: ln y = (exponent) · ln(base), then use the product rule. The power rule u x^(u−1) alone gives only one of the two terms.
  • The exponent is itself a power or a log? Take ln a second time on it. ln(L^(ln L)) = (ln L)² is easy to differentiate.
  • Name the repeated pieces (L = ln x, u = exponent) and differentiate one layer at a time. Each layer gives one factor.
  • Check with a second point. A check at one convenient value can hide a missing term.

The skill here is to simplify an inverse trig expression with a substitution and then divide two derivatives. You did it right in WTA21 Q11 and Q6, and skipped it in CTA21 Q7, which makes the pattern shaky.

CTA21 Q7 · nowSkipped. dy/dz at x = 1/2 with two different inverse-trig functions. Key: √3/10. It needs two different substitutions, one for each function.

Worked example · the exact problem you saw

For x ∈ (0, 1/√2), let y = tan⁻¹((√(1+x²) − 1)/x) and z = tan⁻¹(2x√(1−x²)/(1 − 2x²)). Find dy/dz at x = 1/2.

You skipped this one. Key: √3/10. Here's the working.

Step 1 · simplify y with x = tan θ (√(1+x²) − 1)/x = (sec θ − 1)/tan θ = (1 − cos θ)/sin θ = tan(θ/2). For x ∈ (0, 1/√2) we have θ ∈ (0, π/2), so θ/2 is inside the principal range and y = θ/2 = ½ tan⁻¹x. So dy/dx = 1/(2(1+x²)).
Step 2 · simplify z with x = sin φ 2x√(1−x²) = sin 2φ and 1 − 2x² = cos 2φ, so the fraction is tan 2φ. Here x < 1/√2 gives φ < π/4, so 2φ < π/2 and tan⁻¹(tan 2φ) = 2φ with no shift. That is why the interval is given. So z = 2 sin⁻¹x and dz/dx = 2/√(1−x²).
Step 3 · divide the derivatives dy/dz = (dy/dx)/(dz/dx) = [1/(2(1+x²))] · [√(1−x²)/2] = √(1−x²) / (4(1+x²)).
Step 4 · plug in x = 1/2 √(1 − 1/4) = √3/2 and 1 + x² = 5/4, so the denominator is 4 · 5/4 = 5. dy/dz = (√3/2)/5 = √3/10.
Answer: √3/10
The trap: using one substitution for both. The root √(1+x²) asks for tan, the root √(1−x²) asks for sin. Check where 2θ or 2φ lands before you drop the inverse function.

The shortcuts
  • Spot the substitution. √(1+x²), (1−x²)/(1+x²), 2x/(1+x²), 2x/(1−x²) → x = tan θ. √(1−x²) → x = sin θ (or cos).
  • An inverse function undoes its function only on its principal range: tan⁻¹(tan t) = t for t ∈ (−π/2, π/2); sin⁻¹(sin t) = t for t ∈ [−π/2, π/2]; cos⁻¹(cos t) = t for t ∈ [0, π]. Outside, shift by π or flip the sign.
  • Derivative with respect to another function: dy/dz = (dy/dx)/(dz/dx), never the other way round.
  • Simplify both functions first. Direct differentiation of tan⁻¹(…) with roots inside is long and error-prone.

f(x) = [3x] − {4x}, where [·] is the greatest integer function and {·} the fractional part function. The number of points in [0, 2] at which f is discontinuous is:

Pick one option.

Answer: B · 12
  1. Write −{4x} = [4x] − 4x, so f = [3x] + [4x] − 4x. The line is continuous, so only the floors matter.
  2. [3x] jumps by +1 at x = k/3, k = 1…6 in (0, 2]: 6 points. [4x] jumps by +1 at x = k/4, k = 1…8: 8 points.
