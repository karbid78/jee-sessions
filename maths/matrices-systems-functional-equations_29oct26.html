Worked example · the exact problem you saw

A and B are 3×3 matrices with A² = B² = I, det A = 1 and det B = −1. Then det(A + B) cannot be ... (four numbers in the options).

You marked C and D. The portal ticks all four options, A, B, C and D, so you missed A and B. The four option values were not saved.

Step 1 · what you are given You know A² = I, B² = I and the two determinants. A + B cannot be simplified by itself, so look for a product that contains A + B.
Step 2 · the trick Compute A(A + B)B. Expand: A·A·B + A·B·B = A²B + AB² = IB + AI = B + A. So A(A + B)B = A + B
Step 3 · take determinants det A · det(A + B) · det B = det(A + B). Put in det A = 1 and det B = −1: (1)(−1) · det(A + B) = det(A + B)
Step 4 · the value is forced Let d = det(A + B). Then −d = d, so 2d = 0 and d = 0. The determinant is not “one of several possible values”. It is forced to be exactly 0.
Step 5 · read the words “cannot be” If det(A + B) is always 0, it cannot be any non-zero number. So every option that lists a non-zero number is correct. That is why the portal ticks all four. Quick check with real matrices: A = diag(1, −1, −1) (det 1) and B = diag(1, 1, −1) (det −1) give A + B = diag(2, 0, −2), whose determinant is 0.
Answer: A, B, C, D

Worked example · the exact problem you saw

AX = B, where A = abcsin tcos t−sin tcos tsin tcos t, X = (x, y, z)ᵀ and B = (1, 0, 0)ᵀ. The number of triples (a, b, c) for which the system has infinitely many solutions is ...

You marked option C, which is 2. The key is option A, which is 0. Your working is not saved, so the steps below show the whole route.

Step 1 · write the three equations E1: ax + by + cz = 1
E2: sin t·x + cos t·y − sin t·z = 0
E3: cos t·x + sin t·y + cos t·z = 0Only E1 contains a, b, c. E2 and E3 contain only t, so solve them first.
Step 2 · solve E2 and E3 The two rows are never parallel. If (sin t, cos t, −sin t) = k(cos t, sin t, cos t), the first and third entries give sin t = kcos t and −sin t = kcos t, so sin t = 0; then the second entry gives cos t = 0, which cannot be. So E2 and E3 leave exactly one free direction. Try (x, y, z) = λ(1, −sin 2t, −cos 2t). E2: sin t − cos t sin 2t + sin t cos 2t = sin t + sin(t − 2t) = 0. E3: cos t − sin t sin 2t − cos t cos 2t = cos t − cos(2t − t) = 0. Both hold, so all solutions of E2 and E3 are λ(1, −sin 2t, −cos 2t).
Step 3 · put that line into E1 λ · (a − b sin 2t − c cos 2t) = 1Call the bracket K. Expanding det A along row 1 gives exactly this: det A = K.
Step 4 · count the solutions If K ≠ 0: λ = 1/K, so exactly one solution. If K = 0: the equation reads 0 = 1, so no solution. No value of K leaves λ free, so the system is never consistent with a whole line of solutions.
Step 5 · answer and sanity check No triple works, so the count is 0. Sanity check: K = 0 describes a whole plane of triples, so the count could only be 0 (none of them consistent) or infinite. A small number like 2 could never be the answer.
Answer: 0 (option A)
The trap: “determinant = 0” is needed for infinitely many solutions, but it is not enough. The only non-zero right side sits in E1. When det A = 0, E1 is a combination of E2 and E3, and the same combination of their right sides is 0, so E1 would read 0 = 1. Always ask: if this row depends on the others, do the right sides agree?

The shortcuts
  • Given determinants and A² = I: look for a product like A(A + B)B that contains the thing you want, then take determinants. det(XY) = det X · det Y is all you need.
  • A forced value changes how you read the options. “Cannot be” options are true for every other value. “Must be” options are true for exactly that value. Test each option against it.
  • 3×3 facts: det(kX) = k³ det X, det(Xᵀ) = det X, det(adj X) = (det X)².
  • System AX = B with det A = 0: do not stop. If a row equals α·Row 2 + β·Row 3, the right sides must satisfy the same combination. If they do, infinitely many solutions. If not, it reads 0 = 1 and there is none.
  • Counting (a, b, c) over all real numbers: det A = 0 is a plane of triples, so the count is 0 or infinite. A small count needs a finite set of allowed values (problem 2).

The check-every-option routine
  • Before the options: ask what the question forces (a value, a range, a form) and find it. In Q8 it was det(A + B) = 0.
  • Write T or F beside all four options before you tick anything. No option stays blank.
  • Each T needs a one-line reason. Each F needs a counterexample or a failed check. “It feels true” is not a reason. That is what Q11 cost you.
  • Stuck on one option? Test one concrete case for 30 seconds: x = 0, an end point of the range, or a diagonal 3×3 matrix.
  • Count before you submit. Only 1 or 2 options ticked? Re-check the rest once more. Four options at 45 seconds each is 3 minutes.
Worked example · the exact problem you saw

h(x) = sin⁻¹(2x/(1 + x²)) − cos⁻¹((1 − x²)/(1 + x²)). Select all correct statements. A: h is continuous at every real x. B: h is differentiable at x = 1. C: h′(x) = 0 for x > 1. D: the range of h is [−π, 0].

You marked A only. The portal key is A and D. (The option wording is shortened from the saved test file.)

Step 1 · put x = tan θ Then 2x/(1 + x²) = sin 2θ and (1 − x²)/(1 + x²) = cos 2θ. So h = sin⁻¹(sin 2θ) − cos⁻¹(cos 2θ). Each inverse function returns 2θ only when 2θ is in its own principal range, so split by x.
Step 2 · pieces for x ≥ 0 For 0 ≤ x ≤ 1, 2θ is in [0, π/2]: both terms equal 2θ, so h = 0. For x > 1, 2θ is in (π/2, π): sin⁻¹(sin 2θ) = π − 2θ and cos⁻¹(cos 2θ) = 2θ, so h = π − 4 tan⁻¹x.
Step 3 · pieces for x < 0 Now 2θ is in (−π, 0), and cos⁻¹(cos 2θ) = −2θ. For −1 ≤ x < 0, sin⁻¹(sin 2θ) = 2θ, so h = 4 tan⁻¹x. For x < −1, sin⁻¹(sin 2θ) = −π − 2θ, so h = −π.
Step 4 · option A: continuity Check the joins. At x = −1: 4 tan⁻¹(−1) = −π, matching the flat piece. At x = 0: both pieces are 0. At x = 1: π − 4·(π/4) = 0. No jumps, so A is true.
Step 5 · options B and C: derivative At x = 1 the left slope is 0 and the right slope is −4/(1 + x²) = −2. They differ, so h is not differentiable at 1: B is false. For x > 1, h′ = −4/(1 + x²) ≠ 0: C is false.
Step 6 · option D: range, the one you skipped h is continuous. Its smallest value is −π (flat for x ≤ −1, and also the limit as x → ∞) and its largest value is 0 (on [0, 1]). So the range is [−π, 0]: D is true. A direct check takes seconds: h(0) = 0 and h(−2) = sin⁻¹(−4/5) − cos⁻¹(−3/5) = −0.927 − 2.214 = −π.
Answer: A, D
The trap: ticking A, the first true option, and moving on. D needed only the two end values, 0 and −π, about thirty seconds of work. Q11 was the opposite problem: you ticked C and D, which were wrong, and missed B. Both slips come from not giving every option its own verdict.

The shortcuts
  • Columns defined by A uᵢ = bᵢ: stack them into A u = M. Then det u = det M / det A (when det A ≠ 0).

The shortcuts
  • First substitution: x = y = 0 (or x = 0). It gives f(0), which unlocks the rest.
  • Additive with an extra term, and f′(0) given: put y = h, divide by h, let h → 0. You get f′(x) directly, and differentiability at every point comes with it.
  • Product type f(x + y) = f(x)f(y), f not zero: f(0) = 1 and f′(x) = f(x) · f′(0) (problem 6).
  • Polynomial f: compare degrees, use x = 0 for the constant, then match coefficients. CTA20 Q7: 2d = d + 3 gives d = 3, f(0) = −1, so f = x³ − 1 and f(5) = 124.
  • Arguments that cycle (x → 1/(1−x) → (x−1)/x → x): write the equation at all three, then solve the three linear equations for the f-values (problem 5).
  • Always: put your answer back into the original equation.

A function f : ℝ → ℝ satisfies f(x + y) = f(x) · f(y) for all real x, y. Also f(1) ≠ 0 and f′(0) = 3. Select all correct statements.

Answer: A, B, D
  1. A: put x = y = 0: f(0) = f(0)², so f(0) is 0 or 1. Put x = 1, y = 0: f(1) = f(1)f(0). Since f(1) ≠ 0, f(0) = 1. A is true.
  2. For any x: f(x)f(−x) = f(0) = 1, so f(x) ≠ 0 and f(−x) = 1/f(x).
  3. B: f(x) = f(x/2 + x/2) = f(x/2)² ≥ 0, and it is not 0, so f(x) > 0. B is true.
  4. C: by step 2, f(−1) = 1/f(1), which is positive by step 3. But −f(1) is negative. So C is false.
  5. D: f′(x) = lim [f(x + h) − f(x)]/h = lim f(x)[f(h) − 1]/h = f(x) · lim [f(h) − f(0)]/h = f(x) f′(0) = 3f(x). D is true.
